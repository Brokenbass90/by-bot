# Daily Check — 5-минутный чеклист
**Для:** пользователя (когда меня и Codex'а нет рядом)
**Время:** 5 минут утром

## Шаг 1 — Открой web дашборд (1 мин)

URL: `http://localhost:8765` (или через SSH-туннель: `ssh -L 8765:localhost:8765 root@64.226.73.119` потом открой http://localhost:8765)

Логинься через TOTP.

### Смотри top-bar (новый — будет после моего commit `8447d00` deploy):

| Pill | Что значит | Что делать |
|---|---|---|
| `Today +$X +Nt` (зелёный) | за сутки в плюсе на $X, N сделок | ✅ всё хорошо, иди дальше |
| `Today -$X +Nt` (красный) | за сутки в минусе | проверь recent trades — норма для одной красной сессии. Если 3 дня подряд минус — алерт |
| `last: Xm` или `last: Xh` (серый) | последняя сделка X минут/часов назад | ✅ норма (даже 6-12 часов норма) |
| `last: Xd` (красный + мигает) | последняя сделка >24 часов назад — abnormal | 🚨 проблема! см. шаг 2 |

### Смотри статус справа от top-bar:

| Что показывается | Значение |
|---|---|
| `Live · bull_chop · 0 open` | бот живой, регим bull_chop, открытых сделок нет |
| `Offline` | 🚨 бот мёртв! см. шаг 4 |
| Нет regime | проблема с orchestrator |

## Шаг 2 — Если abnormal (мигает красный) или Offline (1-2 мин)

**Проверь TG канал** — должен быть daily_digest за 08:00 UTC. Если его нет:
- DeepSeek weekly или daily digest сломан

**Проверь watchdog log:**
```bash
ssh root@64.226.73.119 'tail -20 /root/by-bot/runtime/watchdog.log'
```

Если видишь `[WATCHDOG] auto-restart fired` несколько раз — бот падает. Срочно нужен Codex или я.

**Проверь heartbeat:**
Web → /api/status (бот alive если heartbeat_age_sec < 120).

Если heartbeat жив но 0 trades:
- Проверь регим в верху страницы
- Если bull_chop → проверь что v2.1 deployed (overlay file должен существовать на сервере)
- Если регим OK но 0 trades — возможно нет signals (рынок мёртвый), это редко, но бывает

## Шаг 3 — Проверка PnL (1 мин)

В web → раздел "Trades":
- За последние 7 дней должно быть 5-30 сделок (зависит от регима)
- Win rate должен быть 50%+ среди ATT1/ARF1
- Если PnL отрицательный за неделю > -8% — пауза (написать мне или Codex)

## Шаг 4 — Если бот Offline (немедленные действия)

```bash
ssh root@64.226.73.119
systemctl status bybot.service
# Если inactive (dead):
systemctl restart bybot.service
sleep 30
systemctl status bybot.service
# должно быть active (running)
```

Если не запускается — посмотри `journalctl -u bybot.service -n 50` и пиши Codex или мне с этим логом.

## Шаг 5 — Раз в неделю (понедельник, дополнительно 5 мин)

1. Открой `runtime/research_nightly/status.json` через web (либо SSH)
2. Смотри `last_run_ts` — должен быть свежий (< 24 часов)
3. Открой `docs/weekly_reports/deepseek_weekly_*.md` (последний) — DeepSeek отчёт
4. Если есть `runtime/auto_apply_proposals/*.json` — посмотри какой-то новый параметр был auto-applied

## Сигналы тревоги (немедленно писать)

| Сигнал | Серьёзность | Действие |
|---|---|---|
| Bot Offline > 1 час | 🔴 высокая | restart, потом написать Codex/Claude |
| `last: Xd` > 3 дней | 🔴 высокая | возможно регим-bug, restart с проверкой overlay |
| Today PnL < -10% | 🔴 высокая | пауза, не трогать, ждать диагноз |
| 5+ красных дней подряд | 🟡 средняя | пора менять режим стратегий |
| Heartbeat age > 600s | 🟡 средняя | check WS, restart |
| TG digest не приходит 2 дня | 🟡 средняя | check tg_daily_digest cron |
| Funding-carry pos висит > 7 дней | 🟢 низкая | проверь что funding всё ещё в твою сторону |

## Что НЕ паниковать

| Сигнал | Норма? |
|---|---|
| 0 trades за 12 часов | ✅ норма (зависит от регима) |
| 1-2 красных дня | ✅ норма |
| DD до -5% | ✅ норма |
| Регим сменился (bear→bull или наоборот) | ✅ норма |
| `WATCH` статус у одной стратегии | ✅ норма (она сама восстановится) |
| Funding-carry executor не запускается часто | ✅ норма (раз в 8h funding cycle) |

## Чего НЕ делать

- ❌ Не менять `risk_pct` в `.env` без подтверждения
- ❌ Не отключать `bot_health_watchdog`
- ❌ Не запускать новые стратегии в live без backtest
- ❌ Не закрывать руками позиции бота, если только не катастрофа
- ❌ Не менять API keys на Bybit без обновления сервера

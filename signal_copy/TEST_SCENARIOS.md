# Сценарии для теста

Вставляй по одному в окно «Сигналы» и смотри, что скажет бот.
Ожидаемое поведение написано рядом — если реальность разошлась, это баг, присылай.

Важно: цены в примерах фиксированные, а рынок движется. Часть сигналов будет
законно блокироваться как протухшие — это не ошибка, это работа защиты.
Чтобы проверить открытие, бери свежий сигнал из канала.

---

## 1. Обычный сигнал, зона входа, четыре цели
```
✒️BUY AUD/USD

0.70810 - 0.70820

📌Stop loss (SL): 0.70669

• Take profit 1: 0.70892
• Take profit 2: 0.71033
• Take profit 3: 0.71190
• Take profit 4: 0.71295
```
Ждём: `AUDUSD BUY`, зона распознана, взята цель TP4, лот посчитан, зелёная кнопка.

## 2. Два сигнала в одном сообщении
```
✒️BUY XAU/USD

4395 - 4398

📌Stop loss (SL): 4377

• Take profit 1: 4402.1
• Take profit 4: 4436.2


✒️BUY EUR/USD

1.16034 - 1.15950

📌Stop loss (SL): 1.15900

• Take profit 1: 1.16148
```
Ждём: **две** отдельные карточки. Обрати внимание, у EUR/USD диапазон записан
наоборот (сначала большее число) — бот должен переварить.

## 3. Формат Сергея: одна цена вместо зоны
```
📉 SELL XAU/USD

💲4490.525

❌ Stop loss (SL): 4503.723
✅ Take profit: 4464.130
```
Ждём: зона входа схлопнута в одну цену, «Take profit» без номера распознан.

## 4. Однострочный формат
```
GOLD BUY 4390-4393 / SL 4380 / TP 4410 / TP2 4425
```
Ждём: `GOLD` превращается в `XAUUSD`, разделители `/` разобраны, две цели.

## 5. Десятичная запятая
```
SELL XAU/USD 4500,5
Stop loss (SL): 4512,3
Take profit 1: 4480,1
```
Ждём: запятые прочитаны как десятичные разделители.

## 6. Сигнал без стопа — ДОЛЖЕН быть заблокирован
```
✒️BUY EUR/USD

1.16000

• Take profit 1: 1.16500
```
Ждём: ⛔ «сигнал без стопа — торговля запрещена». Кнопки нет.

## 7. Стоп с той же стороны, что и цель — ошибка в сигнале
```
✒️BUY EUR/USD
1.16000
Stop loss (SL): 1.16500
Take profit 1: 1.16800
```
Ждём: ⛔ «BUY: стоп не ниже входа».

## 8. Опечатка на порядок
```
✒️BUY XAU/USD
4400
Stop loss (SL): 438
Take profit 1: 4450
```
Ждём: ⛔ «стоп в … % от входа — похоже на опечатку».

## 9. Неизвестный брокеру символ
```
✒️BUY SILVER
32.50
Stop loss (SL): 32.10
Take profit 1: 33.20
```
Ждём: ⛔ «символа … нет в Обзоре рынка» либо не распознан символ.

## 10. Просьба перенести стоп в безубыток
```
Если у вас консервативная торговля, переносите стоп лосс по AUDUSD в безубыток.
Если риск-менеджмент вам позволяет сидеть дальше, то продолжайте держать позицию.
```
Ждём: карточка «Просят перенести стоп в безубыток», символ AUDUSD.
Если открытых сделок нет — «нет открытых сделок, к которым это отнести».

## 11. Отчёт канала о взятой цели
```
✅ TP 1 - 0.70892 AUDUSD, +82 points
```
Ждём: «Отчёт канала: взята цель», символ и заявленные пункты.

## 12. Отчёт без символа — должен спросить человека
```
❌Stop Loss (SL): 4416,7
```
Ждём: «Отчёт канала: стоп» + «символ не назван — к какой позиции относится?».

## 13. Шум
```
‼️ Через час, в 16:00 МСК будем торговать с Юрием
Встречаемся в прямом эфире
⚡ Ссылку на подключение отправим за 5 минут до начала
```
Ждём: «Шум — не сигнал», ИИ не вызывается.

## 14. Обычный текст
```
Привет, что умеешь?
```
Ждём: «Это обычный текст, а не сигнал» + подсказка про вкладку «Чат».

## 15. Дубль
Вставь любой сигнал **дважды подряд**.
Ждём: во второй раз ⛔ «это сообщение уже обрабатывалось».

## 16. Слишком много позиций
Открой три сделки, попробуй четвёртую.
Ждём: ⛔ «уже открыто 3 позиций из 3».

# Что проверить в чате

- «что у меня открыто?» — должен перечислить позиции со стопами и целями
- «какой сейчас риск?» — должен посчитать от снимка
- «закрой золото» — должен предложить кнопку, а не сделать сам
- Enter отправляет, Shift+Enter переносит строку
- Cmd+V с картинкой прикрепляет её (нужна зрячая модель, см. README)

# Что проверить на позициях

- «В безубыток» при сделке в минусе → должен отказать
- «В безубыток» при сделке в плюсе → сначала браузер показывает точное действие,
  только после подтверждения стоп встаёт в цену входа
- «Закрыть» → сначала точное подтверждение всей позиции, затем она исчезает
- повтор подтверждения/двойной клик → второй вызов отклонён как уже использованный

# Что проверить в Telegram

- сообщение из chat id вне `SIGCOPY_TG_CHAT_IDS` → нет ответа и нет записи сделки
- свежий сигнал → карточка и кнопка, но позиции ещё нет
- кнопка «ОТКРЫТЬ» → один ордер; повторное нажатие отклоняется
- просроченная кнопка (>5 минут) → ордер не уходит
- `/positions` → только живой снимок MT5, без догадок ИИ

# signal_copy — облегчалка торговли по сигналам

Отдельный модуль внутри проекта `bybit-bot-clean-v28`.
Живёт своей жизнью: свой процесс, свой порт, своя база. Удали папку — ничего не сломается.

---

## Зачем это

Есть закрытый Telegram-канал с торговыми сигналами. Раньше путь от сообщения
до сделки выглядел так: прочитать, понять, открыть терминал, посчитать в голове
объём под свой риск, вбить цифры руками, не опечататься. Пять минут и десяток
возможностей ошибиться — а сигнал за это время протухает.

Этот модуль убирает всё, кроме последнего шага. Ты вставляешь сообщение,
видишь готовую карточку с объёмом и риском, жмёшь одну кнопку.

**Он не решает за тебя, входить ли в сделку.** Он считает то, что человек
считает плохо и медленно, и отказывается работать там, где данных не хватает.

## Что умеет

- разбирает сообщения канала без ИИ — правилами, мгновенно и бесплатно
- держит несколько форматов сразу: зона входа и одна цена, одна цель и четыре,
  запятая и точка, несколько сигналов в одном сообщении, разные языки
- отличает сигнал от отчёта, от просьбы перенести стоп и от анонса стрима
- считает объём под заданный риск — для форекса, золота, индексов и акций
- показывает, сколько прибыли реально осталось по текущей цене и какой
  винрейт нужен, чтобы не терять
- открывает сделку в MetaTrader 5 по кнопке
- ведёт открытые позиции: перенос стопа в безубыток, закрытие — тоже через
  отдельное одноразовое подтверждение
- чат про твои же сделки: что открыто, какие стопы, какой риск
- принимает сигнал из локального веб-интерфейса или Telegram allowlist
- пишет в базу каждый шаг: текст, разбор, расчёт, запрос, ответ терминала

## Чего не умеет и не будет

- торговать без твоего подтверждения
- открывать сделку без стопа
- считать объём, когда данные противоречивы — вместо этого отказывается

## Как устроено

```
текст сообщения
   ↓ parser_v2      правила. Обычные сигналы закрывает целиком, бесплатно
   ↓ llm            только если правила не справились
   ↓ sizing         объём от риска, две независимые формулы со сверкой
   ↓ pipeline       карточка превью + одноразовый токен
   ↓ ЧЕЛОВЕК ЖМЁТ КНОПКУ
   ↓ executor       единственный файл, откуда уходит ордер
   ↓ mt5_mcp        127.0.0.1:22346
   ↓ store          в базу пишется всё
```

Связь с терминалом идёт через встроенный в MetaTrader 5 MCP-сервер
(сборка 6060 и новее). Ни советника, ни библиотеки `MetaTrader5`, ни Windows
не нужно — терминал под Wine на маке работает так же, как под Windows.

## Предохранители

Каждый из них появился не из осторожности вообще, а после конкретного случая.

| Что проверяем | Почему |
|---|---|
| объём считается двумя формулами и сверяется, расхождение >5% → отказ | у золота `tick_value` и `contract_size` разошлись в 10 раз, объём вышел бы впятеро больше |
| символ без котировок не считается | свежедобавленный XAUUSD отдавал нули и портил расчёт |
| цена уже за стопом → отказ | сигнал протухает за минуты, стоп оказывается с другой стороны от входа |
| цель уже пройдена → отказ | заходить в отработанное движение незачем |
| рынок ушёл от зоны больше чем на 0.5R → отказ | вход по цене, которой в сигнале не было |
| считаем по цене исполнения, а не из сигнала | ордер уходит по рынку, а не по цене из текста |
| сигнал без стопа → отказ | без стопа размер убытка не ограничен ничем |
| токен подтверждения одноразовый, живёт 5 минут | двойной клик не откроет две сделки |
| close/безубыток требуют нового токена на 90 секунд | чат или чужая вкладка не исполнят денежное действие напрямую |
| повтор того же текста блокируется | одно и то же сообщение легко вставить дважды |
| перед отправкой всё перепроверяется на живых данных | превью могло устареть, пока ты думал |
| торговля только на серверах из белого списка | защита от «подключил не тот терминал» |
| безубыток при сделке в минусе → отказ | это увеличило бы риск, а не уменьшило |
| каждое число из ответа ИИ ищется в исходном тексте | модель не может выдумать цену |
| ИИ не имеет доступа к отправке ордера | `executor` вызывается только из интерфейса по токену |

## Запуск

```bash
cd signal_copy
source ../.venv/bin/activate
python3 app.py
```
Открыть http://127.0.0.1:8766

Нужно: запущенный MetaTrader 5, в нём `Настройки → MCP → Включить внутренний
сервер`. Новый ключ оттуда передаётся **только** через переменную
`SIGCOPY_MT5_TOKEN`; в репозиторий и `config.py` его писать нельзя.

Проверка связи без интерфейса: `python3 check_live.py`

По умолчанию модуль работает в режиме **ТОЛЬКО ПРЕВЬЮ**. После демо-проверки
исполнение включается явно:

```env
SIGCOPY_EXECUTION_ENABLE=1
SIGCOPY_ALLOWED_SERVERS=MetaQuotes-Demo
SIGCOPY_ALLOWED_ACCOUNT_LOGINS=12345678
SIGCOPY_ALLOWED_ACCOUNT_TYPES=demo
SIGCOPY_ALLOW_LIVE=0
```

Для реального сервера потребуются одновременно `SIGCOPY_EXECUTION_ENABLE=1`,
его точное имя в `SIGCOPY_ALLOWED_SERVERS` и отдельное
`SIGCOPY_ALLOW_LIVE=1`. Это не включается одним только наличием токена.

## Настройки — `config.py`

| Параметр | Смысл |
|---|---|
| `RISK_PCT` | риск на сделку, % от средств |
| `MAX_RISK_PCT` | жёсткий потолок, выше — отказ |
| `MAX_LOT`, `MAX_POSITIONS` | лимиты |
| `DEFAULT_TP` | какую цель канала брать, 1..4 |
| `MAX_ENTRY_DRIFT_R` | насколько рынок может уйти от зоны входа |
| `ALLOWED_SERVERS`, `ALLOW_LIVE` | разделение демо и реала |
| `EXECUTION_ENABLE` | общий fail-closed рубильник всех `trade_*` вызовов |

## Telegram (необязательно)

```env
SIGCOPY_TG_BOT_TOKEN=...       # токен отдельного Telegram-бота
SIGCOPY_TG_CHAT_IDS=123456789  # только твой chat id; можно несколько через запятую
SIGCOPY_TG_USER_IDS=123456789  # только твой Telegram user id
SIGCOPY_TG_PRIVATE_ONLY=1      # запрет групп и каналов
SIGCOPY_TG_USE_LLM=0           # правила по умолчанию, без платного API
```

```bash
cd signal_copy
source ../.venv/bin/activate
python3 telegram_bot.py
```

Сообщение создаёт только карточку. Ордер уходит после нажатия inline-кнопки;
кнопка содержит одноразовый токен и протухает через 5 минут. Неавторизованные
chat id молча игнорируются. Команда `/positions` читает позиции терминала.

## ИИ

Правила разбирают обычные сигналы сами, модель при этом не вызывается —
платить не за что. Она подключается только на свободном тексте.

```env
SIGCOPY_LLM=ollama            # локально и бесплатно по умолчанию
OLLAMA_MODEL=qwen2.5:7b
OLLAMA_VISION_MODEL=llava     # нужен, чтобы читать картинки в чате
DEEPSEEK_API_KEY=...          # только необязательный fallback
```

## Файлы

| Файл | Что делает |
|---|---|
| `app.py` | веб-интерфейс: сигналы, позиции, чат, график |
| `parser_v2.py` | разбор сообщений правилами |
| `llm.py` | ИИ-слой с проверкой выдуманных чисел |
| `sizing.py` | расчёт объёма от риска |
| `pipeline.py` | сборка карточки превью |
| `executor.py` | отправка ордера, закрытие, безубыток |
| `mt5_mcp.py` | клиент MCP-сервера терминала |
| `chat.py` | разговор про свои сделки |
| `telegram_bot.py` | allowlisted Telegram-вход с ручной кнопкой исполнения |
| `store.py` | база: сообщения, сделки, исполнения, лог решений |
| `calibrate.py` | замер настоящей стоимости пункта опытом на демо |
| `check_live.py` | проверка связи |
| `TEST_SCENARIOS.md` | что вставлять для теста |

# PREREG POGLOSHCHENIE_H1 — поглощение агрессора / провал ценового импульса (14.10.2026, Claude CRO; GO PM 14.10).
Написан ДО скачивания данных. Семья POGLOSHCHENIE (дневная форма V1 — FAIL 14.10); это новая форма: внутри часа, новые данные.

## Механизм
Если за час прошла аномально большая агрессивная продажа, а цена не упала — предложение кто-то поглотил (крупный пассивный
покупатель). Пассивная сторона информирована/терпелива и продолжит покупать → следующие сутки цена растёт. Симметрично для
агрессивной покупки без роста. Вопрос не «сколько купили» (KITY), а «сколько цена сдвинулась на единицу потока».

## Данные и вселенная
`fabrika/dannye_binance_h1.py`: часовые свечи Binance USD-M (open, close, объём $, агрессивные покупки $).
Монета участвует в день D, если она в PIT топ-50 по OI на последнем недельном снимке с датой ≤ D−1.
Период: 2021-07 … 2026-09.

## Событие (точно)
Для часа h монеты: N = 2·taker_buy_quote − quote_vol (чистый агрессивный поток, $); n = N / среднее(quote_vol) за 720
предыдущих часов; r = close/open − 1. По 720 предыдущим часам (минимум 500): zN = (n − mean)/sd.
- SELL_ABSORB: zN ≤ −3 и r ≥ 0 → ЛОНГ.   BUY_ABSORB: zN ≥ +3 и r ≤ 0 → ШОРТ.
- Вход: закрытие часа h. Выход: закрытие часа h+24. Без стопов. Пока позиция по монете открыта — новые события монеты не берутся.
- Издержки: 12 bps на круг (как у всех крипто-тестов фабрики) + фактический фандинг Binance за удержание (data/binance_kity/funding).

## Контроль механизма (базовая группа, не стратегия)
NORMAL: zN ≤ −3 и zr ≤ −1 (цена упала как обычно; zr — z доходности часа по тем же 720 ч) → та же сторона, что у SELL_ABSORB
(и зеркально для покупок). Механизм верен, только если поглощённые события лучше обычных: ABSORB − NORMAL > 0.
Челленджер: НЕТ (одна базовая форма, без перебора порогов/горизонтов).

## Независимость от KITY (до PnL, без доходностей)
Для каждого события — дециль монеты по KITY m3 на последнем недельном сигнале; ранговая корреляция «сторона события × KITY-ранг».
|корр.| > 0.5 → гипотеза снимается как дубликат KITY до PnL.

## Тест (один) и критерий
Записи — в OpportunityRecord V1 (factory_v3/opportunity_v1.py), data/opportunities/POGLOSHCHENIE_H1_v1.csv.gz.
t — по дневным кластерам (среднее по событиям дня), Ньюи–Уэст лаг 1.
Главное окно 2023-01 … 2026-09 (реестр KRIPTO_H1M5_2023_2026Q3): PASS ⇔ средний net > 0, t ≥ t_req реестра, обе половины > 0,
и ABSORB − NORMAL > 0 с t ≥ 1.0. Репликация 2021H2–2022 (KRIPTO_D1_2021H2_2022): тот же знак net (без требования значимости).
Отчёт: покрытие → независимость → результат → эпохи (2021H2–22 / 2023 / 2024 / 2025–26) → чувствительность к издержкам
(0 / 12 / 24 bps) → KEEP/KILL. PASS → только право на форвард (CONFIRM), не деньги.

## Измеримый эффект: наклонные линии (главная находка)
H1-бары 16 монет, окно 120 ч, шаг 24 ч, 11 424 линии поддержки/сопротивления:
| построение | линий «целых» (не пробиты закрытием) |
|---|---|
| старое (регрессия через все пивоты окна) | **0 из 11 424 = 0 %** |
| исправленная проверка, все пивоты | 0 % |
| через последние 3 точки (`last_pivots=3`) | 48.5 % |
| через последние 2 точки | 72.9 % |
Вывод: прежний `sloped_level` на реальных данных НИ РАЗУ не дал пригодной наклонной — регрессия через все минимумы/максимумы окна
не похожа на линию трейдера. Ветки `require_unbroken=True` в pump_exhaustion_unwind_short_v1 и fx_setups_v2 из-за этого
фактически не работали. Это подтверждает замечание владельца «отрисовку наклонных надо корректировать». Новое построение —
опция; существующие стратегии не меняются, пока не будет A/B.

## Дополнение (PM 21.10, 14:20): изменились ли торговые решения после c80712c
- Причинность: тест replay по одному закрытому бару (`test_naklonnaya_prichinnost_replay_po_odnomu_baru`): каждая точка линии
  подтверждена `right` барами к моменту построения; решение на баре t при пересчёте с тем же срезом не меняется. 65 тестов PASS.
  Новая подтверждённая точка меняет линию только на следующих барах — это не заглядывание.
- pump_exhaustion_unwind_short_v1 (не путать с замороженным PUMP4 V1 = pump_fade_v4r): та же конфигурация, что в стратегии
  (5m, окно 144 бара, пивоты 2/2, ≥ 2 точки, R² ≥ 0.45, require_unbroken), 32 000 случайных окон по 16 монетам:
  | геометрия | наклонная найдена |
  |---|---|
  | A — старая | 0 % |
  | B — исправленная, по умолчанию | 0 % (ни одного окна, где решения A и B расходятся) |
  | B — через последние 3 точки (опция) | 33.4 % |
  | C — фильтр наклонных выключен | наклонная не участвует |
  Наклонная в этой стратегии — один из трёх якорей (горизонталь / наклонная / максимум ликвидности, берётся наибольший пробитый).
  Раз старая геометрия не находила линию никогда, A ≡ C: **торговые решения после c80712c не изменились (NO_IMPACT)**, а все
  прежние экономические тесты этой стратегии наклонную геометрию фактически не проверяли.
- fx_setups_v2: тот же путь `require_unbroken=True` по умолчанию → ожидается то же (решения не меняются); FX-данных в этом
  окружении нет — формально UNKNOWN до прогона на FX-барах. FX-направление закрыто 30.09, приоритета нет.
- Порог «≥ 30 % целых линий» как регрессионный тест не вводится; регрессия — синтетика (целая/сломанная линия), причинный replay
  и фиксированная выборка (числа выше) для обнаружения неожиданных изменений.

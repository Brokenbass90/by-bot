# План: автономная Factory + Portfolio Brain + AI (Claude, 17.10.2026)

Цель: система сама находит механизм → проверяет без подглядывания → ставит в тень → Brain решает, когда и сколько →
человек видит в Telegram «что найдено, что проверено, что решено, какой результат». ИИ предлагает и проверяет; деньги,
риск и production-код меняют только детерминированные ворота и письменное GO.

## 2. Узкие места (измерено, не предположено)
1. **Бюджет DEV-окон.** KRIPTO_D1_2023_2026Q3: 12 из 20 попыток после сегодняшних заявок. При темпе 3–5 в неделю окно
   кончится за 2 недели → дальше требуемый t растёт, а новых окон нет. Нужен **план окон**, иначе Factory встанет.
2. **Поток кандидатов, а не инфраструктура.** 117/126 семей убиты; живые находки пришли из НОВЫХ данных
   (KITY — стакан; Elder — режим; ETF_PREMIYA — биржевая премия). Источник новизны = новые данные, а не перебор форм.
3. **Нет прямой обратной связи «тень → Brain → вердикт».** Тени пишут исходы, но решение KEEP/KILL по тени — вручную.
4. **Деградация не отслеживается автоматически:** нет сравнения живого распределения исходов с бэктестным.
5. **ИИ-раунд не в цикле:** запускается руками, выход не проходит независимое ревью автоматически.

## 3. Целевой цикл (один оборот = одна неделя, без участия человека, кроме GO)
```
новые данные → Data QA → каталог → ИИ предлагает механизмы (контракт) → кладбище/дубли → Claude-ревью механизма
→ измерения без доходностей (закрытый список) → заморозка (prereg-JSON) → ферма (DEV, бюджет) → PASS → тень (CONFIRM вперёд)
→ судья тени (KEEP/KILL по prereg) → Brain включает в политику → отчёт в TG → GO владельца → micro-LIVE
                                    ↑ при KILL: автопостмортем → 2 новых механизма в резерв ┘
```

## 5. Проверки качества самой системы (кто сторожит сторожа)
- **Известные ответы** (`kontrol_fermy`): ферма обязана воспроизводить замороженные числа; расхождение → ТРЕВОГА, конвейер стоп.
- **Подложенный edge / шум**: ложные срабатывания ≤ 5 %, мощность на 150 bps ≥ 50 % — еженедельно.
- **Причинность времени**: синтетический ряд с задержкой доступности 30 дней обязан давать 0 сделок (уже есть для шаблонов v2).
- **Учёт попыток**: результат без зарегистрированной попытки отвергается; одна попытка — один результат.
- **Независимое ревью**: PASS на DEV → ревью Claude (или вторая модель) по prereg и коду ДО тени; LIVE-паритет — как сделали
  с Alpaca (эталон, replay, 1e-9).
- **Кладбище**: воскрешение семьи — только с записанной новизной (DANNYE/INSTRUMENT/KONTEKST/MEHANIZM), лимиты в реестре.

## 6. Чего ИИ не делает никогда
Пороги, критерии, окна, бюджеты, размер, риск, ордера, статусы выше NEW, production-код без тестов и ревью.
Иногда лучшая адаптация — остановить рукав: судья тени и детектор деградации имеют право сказать KILL/STOP, Brain — уйти в кэш.

## 7. Метрики, по которым видно, что система работает
кандидатов в неделю, прошедших измерения · доля DEV PASS, подтверждённых вперёд · время идея→вердикт · число живых
независимых рукавов (корреляция < 0.3) · доход портфеля vs BASELINE на одних возможностях · минуты без защиты (LIVE).

# PREREG: KITY_POZICII — заморожено 2026-10-03 ДО загрузки данных и ДО любого взгляда на доходности

## Механизм (уровень тезиса)
KITY_PROTIV_TOLPY: позиции крупных трейдеров Binance (взвешенные размером) несут информацию, которой нет у толпы.
Ставка — **за китами**: лонг монет, где крупные деньги сильнее всего в лонге, шорт — где сильнее всего в шорте.

Другие колонки Binance не перебираются.

## Сигнал (заморожен)
- Дата d — сетка раз в 7 дней с 2021-07-01. Вход закрытием дня d, удержание 7 дней.
- Признак: M2 в 00:00 UTC дня d−1 (первая точка в [00:00, 00:15]) — тот же тайминг, что L1 TOLPA.
- Вселенная: PIT топ-50 по sum_open_interest_value в 23:55 дня d−1, снятые с торгов включены, ≥ 60 дневных баров истории,
  ≥ 30 монет с признаком. Лонг верхнего дециля M2, шорт нижнего (k = n//10).
- Сделка: закрытие→закрытие, фандинг Binance, 12 bps на круг; монета исчезла в удержании → выход по последнему закрытию.

## Окна (каждое — один прогон, результат финальный)
- **PRIMARY**: входы 2023-01-01 … 2026-09-23 (выход до 2026-09-30). Для признака M2 история нетронута; цены этого
  окна видели другие механизмы — сказано заранее.
- **REPLICATION**: входы 2021-07-01 … 2022-12-31 (другой режим: бык 2021, крах 2022).

## Вердикт
- PRIMARY PASS ⇔ среднее > 0, обе хронологические половины > 0, сырой > 0, t Ньюи–Уэста (лаг 1) ≥ 2.0, ≥ 52 недель.
- REPLICATION: `CROSS_PERIOD_PASS` (те же условия, кроме ≥52 недель — там 79) / `SAME_SIGN` (среднее > 0, t < 2) / `OPPOSITE`.
- Независимость: корреляция недельных доходностей KITY с L1-толпой, посчитанной на тех же данных Binance;
  |корр.| < 0.5 — независимая нога; иначе — производная TOLPA (доказательства не складываются).
- Максимальный статус Claude: `HISTORICAL_REPLICATION_PASS` / `READY_FOR_BUILD` ⇔ PRIMARY PASS + REPLICATION не OPPOSITE + независимость. Дальше — пакет Codex: исполнение/издержки/риск/выбранный счёт; canary — следующий слой, не решение Claude. (Уточнение терминов 03.10 до данных; правила не изменены.)

## Бюджет спасения
PnL FAIL → причинный постмортем (данные, прокси, издержки, режим, горизонт, ёмкость, нет механизма).
Разрешён ОДИН новый prereg-вариант, только если он следует из диагноза и записан до взгляда на его исходы.
Разворот знака как «спасение» запрещён. Перебор порогов/удержаний/таймфреймов запрещён. После этого — KILL.

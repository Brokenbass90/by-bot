## Две роли

1. **Сенсор** для существующих механизмов (POLY_SENTIMENT_V1) — этот документ.
2. **Отдельный слот «рынки предсказаний»** для собственных стратегий (связанные рынки,
   ликвидность, дисбаланс стакана). Они требуют снимков стакана, которых в истории нет,
   поэтому сначала копятся вперёд (`poly_sbor.py --snimki`), тесты — позже, отдельной
   предрегистрацией.

Только чтение: без ключей, кошелька и ордеров. Торговля на Polymarket зависит от страны;
перед любым исполнением обязательна программная проверка географической доступности.
До доказанного эджа этого вопроса нет.

## Маппинг событие → рынок (`poly_map.json`)

Категории: снижение ставки ФРС (+1), повышение (−1), рецессия (−1), высокая инфляция (−1),
крипто-регулирование/ETF (+1), крипто-цена «выше X» (+1). Получатели: крипта и/или акции.
Рынок без категории не участвует. Минимальный объём рынка 00k.

## POLY_SENTIMENT_V1 (`poly_priznaki.py`)

Для дня t: по рынкам, которые уже начались, не заканчиваются в ближайшие 24 ч и сутки
назад были в [0.03, 0.97]: вклад = знак × (p(t) − p(t−24 ч)); признак получателя —
среднее вкладов. Веса равные (итоговый объём известен только задним числом).
Проверки (5/5): скачок виден в свой день, а не раньше; решённый рынок не участвует;
рынок без маппинга не участвует; крипто-цена не идёт в признак акций; за 24 ч до
окончания рынок выпадает.

## Первый тест: BULL_VOL_EXPANSION_POLY

Тот же вход, что у BULL_VOL_EXPANSION_BASE (сжатие → расширение, топ-50 по OI в долларах),
но только в дни, когда признак для крипты > 0 (рынки предсказаний сдвинулись в risk-on).
Вопрос: добавляет ли Polymarket информацию механизму. Судья портфельный: эффективных
периодов ≥ 20, обе половины > 0, t ≥ 2.5 → находка → подтверждение после 2025-10-01.
Сравнение с базой (эдж база t = 1.07) — диагностика, не вердикт.
Честная оговорка: у базы 34 эффективных периода; фильтр их уменьшит — возможен LOW_N.

## Поправка 1 — ворота данных (сам тест не меняется)

1. Каталог Gamma листается окнами по дате окончания (потолок offset ~2000 давал HTTP 422).
2. Маппинг смотрит не только вопрос рынка, но и событие: title/slug/seriesSlug/теги.
3. История запрашивается по токену ДА из clobTokenIds (не по id рынка); 0 точек у рынка 2020 года —
   это рынок до CLOB, а не ошибка идентификатора. Перед массовой загрузкой — `--proverka_rynkov`
   (событие → рынок → токен → число точек на ~10 рынках).
4. Ворота покрытия: признак считается только в дни с ≥3 рынками; тест BULL_VOL_EXPANSION_POLY
   получает BLOCKED_DATA, пока таких дней меньше 60% в окне обнаружения (с 2023-03).
   Содержательного вердикта до этого нет.

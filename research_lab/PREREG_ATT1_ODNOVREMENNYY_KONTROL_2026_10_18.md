# PREREG ATT1_ODNOVREMENNYY_KONTROL — есть ли у события ATT1 информация против ОДНОВРЕМЕННОГО случайного входа (18.10.2026, до расчёта)
Повод: в тени ATT1 (07.09–18.10, 2 257 решений) R − контроль(случайный момент истории той же монеты) = +0.054R, t 3.85 по дням,
но контроль не одновременный (`ATT1_VOSSTANOVLENIE_ISTORII_2026_10_18.md`). Проверяем честно, на уже записанных решениях.

Данные: решения `data/ten_ATT1.jsonl` с исходом (как есть на 18.10), часовые свечи Bybit linear всех монет тени,
снятые одним снимком хуком `fabrika/kesh_att1.py` (публичный API, без ключей) в `data/h1_kesh_att1/`.
Для каждого решения (монета s, бар ts, шорт, stop_dolya, rr1, rr2, f1 = 0.55 если не записан, hold 336):
- СВОЙ = sim_geo(свечи s, бар ts, …) — та же функция, что контроль ten.py, чтобы сравнивать одним измерителем;
- КОНТРОЛЬ = среднее sim_geo по 20 случайным ДРУГИМ монетам тени, у которых есть бар ts (тот же час, та же сторона, та же
  геометрия в долях цены и R); seed 20261018.
Разница d = СВОЙ − КОНТРОЛЬ; кластеры — сутки решения.

PASS (все): среднее d > 0; t по суткам ≥ 2.5; обе хронологические половины > 0; ≥ 5 из 7 недель > 0.
PASS → у события есть информация сверх рынка в тот же час → гипотеза ATT1_NEJTRAL (шорт ATT1 + лонг корзины) получает свой
prereg и тень; денег не даёт. FAIL → семья ATT1 остаётся KILL, тень ATT1 можно остановить (решение владельца).

## Дополнение 1 (18.10, до получения свечей и любого расчёта) — покрытие и смещения
- Снимок: limit=1000 часовых баров на монету ≈ 41.7 суток назад от момента скачивания (18.10) → начало ≈ 06.09; первое решение
  тени 07.09 15:00 — покрыто. Решения, у которых окно 336 ч после входа НЕ помещается в снимок (вход позже ≈ 04.10), исключаются
  и для СВОЕГО, и для КОНТРОЛЯ — отбор по времени входа, не по исходу. Число исключённых публикуется.
- Монеты без свечей в снимке (сняты с торгов/ошибка API) исключаются как СВОИ; их число публикуется (оценка смещения выживших).
- Издержки: и СВОЙ, и КОНТРОЛЬ считаются одной функцией sim_geo (6 bps на сторону × плечо) — расходы одинаковы по построению.
- Причинность: вход — открытие бара после сигнального; ни СВОЙ, ни КОНТРОЛЬ не используют бары до входа для исхода.
Критерии PASS/FAIL не меняются.

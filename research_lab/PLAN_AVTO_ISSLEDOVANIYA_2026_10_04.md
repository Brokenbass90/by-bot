## 5. AUTONOMOUS_SHADOW_RESEARCH_V1 — расширение Фабрики, не замена
```
сборщики → health/coverage digest (детерм.) → Ollama-аналитик (раз в 6 ч / по событию) → проверка семьи/дублей
→ ОДИН активный слот гипотезы → prereg с хэш-замком ДО PnL → дешёвая фальсификация → замороженный исторический прогон
→ детерминированный судья → неизменяемая квитанция → KARTA → READY_FOR_BUILD / KILL / BLOCKED_DATA
```
Права Ollama: читать digest и кладбище, группировать аномалии, предложить ≤ 3 гипотезы в JSON-схеме (механизм, измерения 2–3, данные, сторона), объяснить результат, выбрать следующий **разрешённый** тест из белого списка. Запрещено: shell, правка кода/порогов, второй прогон после результата, деньги, брокер.
Claude просыпается только на: READY_FOR_BUILD, BLOCKED_DATA, конфликт доказательств, решение по бюджету спасения.

# FX/Gold адаптер — спецификация V1 (13.10.2026). Только дизайн и fixtures, без PnL.
Код: `research_lab/factory_v3/fx_kontrakt_v1.py`, тесты `factory_v3/tests/test_fx_kontrakt_v1.py`.

## Почему начинаем с издержек
30.09 FX/Gold закрыт: 53 пункта, эффекты были, но не переживали спред/своп (ночной дрейф fx7: +2.28 bps валовых — неисполним).

## Инструменты (старт): XAUUSD, EURUSD, GBPUSD, USDJPY
| поле | смысл | откуда в бою |
|---|---|---|
| point, kontrakt, kotirovka | шаг цены, единиц на лот, валюта котировки → стоимость пункта (USDJPY делится на цену) | спецификация символа брокера |
| lot_shag, lot_min | кратность объёма | брокер |
| min_stop_pt | минимальная дистанция стопа (stop level) | брокер |
| komissiya_usd_lot_storona | комиссия | тариф счёта |
| svop_long_pt / svop_short_pt, utroennyy_den | своп за ночь и день утроения (обычно среда) | спецификация символа (меняется! снимать ежедневно) |
| bid / ask | котировки, спред по сессиям | **атлас FX**: снимки bid/ask каждые N минут, как kripto_atlas |

## Время (главная ловушка)
- Торговый день закрывается в **17:00 America/New_York** (ролловер, своп). Сервер MT5 «NY+7»: UTC+2 зимой США, UTC+3 летом.
- США и Европа переводят часы в разные даты → ~3 недели в марте и ~1 неделю осенью смещения Лондон/NY другие. Только zoneinfo.
- Рынок открыт вс 17:00 NY → пт 17:00 NY. Котировка в закрытом рынке = дефект.
- Сессии по местному времени городов: ASIA / LONDON / OVERLAP / NY; спред атласа агрегируется по сессиям.

## Издержки круга
спред (вход по ask/bid, выход по bid/ask против середины) + комиссия×2 + свопы по каждому ролловеру внутри удержания
(тройной в utroennyy_den) → USD. Fixtures помечены `fixture=True`; `boevoy=True` с fixtures — исключение.

## Контекст (отдельный от крипты)
FX: режим USD (DXY-прокси), сессия, ставки/дифференциал, волатильность, макро-календарь. Gold: USD + реальные ставки + risk-off + сессия.
Общий Brain получает их в унифицированном виде, но не подменяет BTC-режимом.

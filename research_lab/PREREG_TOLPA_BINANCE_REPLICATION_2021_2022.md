# PREREG: TOLPA_BINANCE_REPLICATION_2021_2022 — заморожено 2026-10-03 ДО скачивания данных Binance

Статус: **кросс-биржевая историческая репликация** механизма семьи TOLPA («перегруженная лонгами толпа → относительная
слабость»), а НЕ holdout той же Bybit-стратегии. Другая биржа, другая толпа, другой цикл (2021 бык, 2022 крах).
Решение менеджера 03.10. Bybit 2020–2022 отвергнут пробой глубины (`glubina_istorii.py`): вселенная из выживших.

## Данные (Binance USD-M, публичный архив data.binance.vision, без ключей)
- metrics (5-мин): `count_long_short_ratio` (отношение лонг/шорт аккаунтов), `sum_open_interest_value` (OI в $);
- klines 1d; fundingRate (месячные файлы). Снятые с торгов монеты включаются (список символов — листинг архива).
- Окно сделок: вход 2021-07-01 … 2022-12-31 (последний вход, выход может быть позже — данные до 2023-01-15).
  Прогрев: свечи с 2021-04-01.

## Перенос правил с Bybit (все отличия записаны ДО данных)
| элемент | Bybit (пачки 7/8) | Binance (здесь) |
|---|---|---|
| признак толпы | buyRatio (доля лонг-аккаунтов) | count_long_short_ratio; порядок монет тот же (доля = r/(1+r) монотонна) |
| L1 (недельная) | значение за предыдущие сутки (метка d−1 00:00) | значение в 00:00 UTC дня d−1 |
| TOLPA_1D (дневная) | 22:00 UTC дня d | 22:00 UTC дня d |
| вселенная | PIT топ-50 по OI×цена, строго до даты | PIT топ-50 по `sum_open_interest_value` на 23:55 дня d−1 (строго до даты), снятые включены |
| сделка | закрытие→закрытие, фандинг, 12 bps на круг | то же; фандинг Binance |
| монета исчезла в удержании | сделка выпадала (None) | **выход по последнему закрытию** (иначе снятые LUNA/FTT молча выпадают) |
| ребаланс L1 | каждые 7 дней | каждые 7 дней начиная с 2021-07-01 |
| мин. монет на дату | 30 | 30 |

## Конечные точки и вердикт (один прогон, результат финальный)
- **PRIMARY — L1 недельная** (исходная стратегия семьи): PASS ⇔ среднее > 0, обе хронологические половины > 0,
  t Ньюи–Уэста (лаг 1) ≥ 2.0, ≥ 52 недель.
- **SECONDARY — TOLPA_1D**: тот же набор условий (лаг 1). Поддерживающая; НЕ может спасти провал primary.
- PRIMARY FAIL → **семья TOLPA KILLED** (и недельная, и дневная), без ожидания 180/365 дней.
- PRIMARY PASS → статус `CROSS_VENUE_HISTORICAL_REPLICATION_PASS`.

## Замена обязательного ожидания 180/365 (решено сейчас, до данных)
`READY_FOR_BUILD` для TOLPA, если ВСЕ:
1. Binance 2021–2022 PRIMARY (L1) PASS по этому документу;
2. существующий Bybit holdout 2026-04…09-04 остаётся того же знака (+248 bps) и не опровергается;
3. текущая теневая/вперёд-линия Bybit (`tolpa_vpered.py`, `tolpa1d_vpered.py`) подтверждает корректность данных,
   причинность (нет заглядывания) и свежесть исполнения — это проверка, а не статистический порог;
4. отдельные ворота издержек/исполнения PASS.
TOLPA_1D — поддерживающая, не отдельное независимое доказательство. Пороги и сигнал после результата не меняются.

## Поправка A1 — 2026-10-04, ДО любого PnL (диагностика покрытия, доходности не считались)
Ворота покрытия `manifest_binance.py tolpa` дали C3 = 54/79 недель → BLOCKED. Причина — архив, не загрузка:
metrics Binance до 2021-12-01 есть только по BTCUSDT (первая дата у 137 альтов — 2021-12), в 2022-01
count_long_short_ratio пуст у большинства монет (1644 из 4201 точек). Окно с данными: 2021-12…2022-12 без января,
**54 недели ≥ 52** (минимум prereg). Судья не меняется: даты с < 30 монет он и так пропускает.
C3 по поправке: «недель с ≥ 30 монетами ≥ 52». Следствие, сказанное до результата: бык 2021 не покрыт,
репликация — в основном режим краха 2022; мощность ниже задуманной. Пороги вердикта не меняются.

# Предрегистрация: MPL V3
Объявлено 12 августа 2026. Заменяет V2, которая умерла до вскрытия.

## Почему V2 закрыта, а не исправлена
Отладочный прогон V2 на 15-минутках дал **75 сигналов за 2.75 года**,
то есть примерно 20 сделок на девятимесячный запечатанный период при
объявленном минимуме 150. Вскрывать холдаут ради 20 сделок бессмысленно:
запечатанный период тратится один раз.

Разбор по фильтрам показал, где всё умирало:
```
объём >= 2.5 медианы          выживает  6.1%
расстояние до уровня 2.5-4.5  выживает  6.0%   <- главный убийца
откат 30-60%                  выживает 10.0%
```
Оба ужесточения V2 (объём 2.5 и расстояние 2.5-4.5) были выбраны
ПОСЛЕ просмотра корзин V1. То есть подогнанные пороги не просто
рисковали ложным плюсом — они физически сделали ногу непроверяемой.

## Что делает V3
Возвращается к порогам V1, которые были объявлены ДО первого прогона
и никогда не подбирались под результат. Расширяется УНИВЕРСУМ, а не
смягчаются условия входа: число инструментов — это не порог, влияющий
на исход сделки, а охват.

```
пороги входа        ровно как в V1 (объём 1.5, расстояние 1.0-6.0,
                    откат 30-60%, импульс 2 ATR, верх 20%)
точка входа         15-минутный бар (обстановка считается на часовых)
универсум           62 символа с оборотом >= $5 млн/сутки (было 35)
удержание           24 часа + продление при живом импульсе, потолок 168
                    (выбрано по критерию «лучший худший год», не по среднему)
издержки            комиссия 6 bps на сторону
                    проскальзывание: >$100M -> 2, $20-100M -> 4,
                    $5-20M -> 8 bps на сторону
                    фандинг 1 bp / 8 часов по факту
                    выход по времени: +2 bps
сторона             только лонг
```

## Отладочный прогон (частота, не эдж)
```
700 сигналов за 2.75 года на 61 символе = 21 в месяц на портфель
на девять месяцев холдаута ожидается ~190 сделок  -> порог 150 пройден
правило продления срабатывает в 8% сделок -> в коридоре 5-50%,
   пересчёт периода EMA не требуется, параметр заморожен
```

## Поправки измерительного контракта до вскрытия (аудит Codex)

Результат холдаута ещё не читался. До одноразового запуска исправлены только
границы и контроль, торговые пороги V3 не менялись:

- точное окно данных `[2025-10-01 00:00Z, 2026-07-01 00:00Z)`;
- новые сигналы цензурируются за 168 часов до конца, чтобы их исход не читал
  июль за границей экзамена;
- ровно 62 файла из зафиксированного allowlist, лишние `.npz` игнорируются;
- входы контроля берутся из того же символа и того же holdout-окна;
- копируются риск в процентах и фактическое расстояние до цели;
- сигнал исполняется только по open следующего 15-минутного бара; invalid
  gap через стоп/цель не превращается в сделку;
- две позиции одного символа не перекрываются: новый сигнал допускается только
  после фактического выхода предыдущего;
- ярус проскальзывания определяется trailing 24h turnover, известным в момент
  решения, а не медианой всего будущего периода;
- три календарных квартала проверяются как Q4 2025, Q1 и Q2 2026;
- фиксированные издержки фандинга `1 bp / 8 часов` являются консервативной
  моделью, а не заявлением об историческом фактическом funding.

Сборщик перед агрегацией сортирует 5-минутные бары по timestamp. Runner
fail-close проверяет UTC-границы, OHLC-геометрию, покрытие, точный универсум,
хэши кода/предрегистрации и создаёт write-once manifest до чтения NPZ.

## Бенчмарк случайного входа
Для каждого сигнала один случайный 15-минутный бар того же символа,
равномерно по запечатанному периоду, где определены ATR и уровень.
Копируется риск в процентах, расстояние до цели в абсолюте, правило
удержания. Сделки, где стоп выбивает сразу, учитываются как -1R,
а не выбрасываются. Зерно 3.

## Критерий смерти
Мертва, если на запечатанном периоде 2025-10..2026-06 выполнено любое:
  * средний R после издержек <= 0
  * превышение над случайным входом < 0.05R
  * сделок меньше 150

## Критерий приёмки
Кандидат в тень, только если ВСЕ:
  * средний R после издержек > 0
  * превышение над случайным входом > 0.05R
  * нижняя граница 95% интервала (недельный блочный бутстрап) > 0
  * сделок >= 150
  * положительны все 3 календарных квартала экзамена
  * знак R одинаков в обеих половинах периода, ни одна не хуже -0.02R

Даже при выполнении всех шести — не деньги, а теневой сбор
до 30-50 проспективных закрытых сделок.

## Запрещено
Любое изменение порогов после вскрытия. Вскрытие одно.

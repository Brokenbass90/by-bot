# PREREG PUMP4_REZHIM_SHIRINA — в каком режиме у PUMP4 V1 есть преимущество (26.10.2026; гипотеза сформирована на просмотренных данных,
проверка — только вперёд). PUMP4 V1 не меняется; это фильтр-кандидат для будущего решения, а не правка исполнителя.

## Механизм
PUMP4 шортит памп отдельной монеты. Одиночный памп — локальный перегрев, который откатывает. Если пампы идут волной по многим монетам
сразу, это рыночный разгон альтов (импульс), и шорт против волны проигрывает.
## Признак (доступен до сделки)
Ширина = число решений PUMP4 (по всем монетам, журнал тени) с меткой сигнала в окне [ts − 24 ч; ts) — строго до сигнала.
## Как сформирована гипотеза (раскрываю)
На 72 закрытых сделках 04.09–22.10 (forward + OOS, `results/pump4_pereschet_20261025T0639Z.json`):
ширина 0 — 13 сделок, +0.271R, 1 убыточная; 1–2 — 16, +0.115R, 4; 3–5 — 20, +0.075R, 5; ≥ 6 — 23, +0.009R, 8.
Это наблюдение задним числом; сентябрьская волна и эти 72 сделки для подтверждения **не используются**.
## Проверка (заморожено)
Только решения тени PUMP4 с меткой сигнала **после коммита этого prereg**, закрытые по правилам pump4_pereschet (V1 как есть).
Сравнение: группа «ширина ≤ 2» против «ширина ≥ 3» по среднему R; t с кластерами по дням сигнала.
Вердикт на ≥ 40 закрытых сделках (или 31.03.2027): PASS — разница > 0, t ≥ 2.0, и среднее «≤ 2» > 0 при фактических расходах V1;
FAIL — разница ≤ 0; иначе INCONCLUSIVE. При PASS — отдельное решение владельца/PM о фильтре для V1 (не автоматически).

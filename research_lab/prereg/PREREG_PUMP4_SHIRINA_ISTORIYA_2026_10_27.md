# PREREG PUMP4_SHIRINA_ISTORIYA — единственный вариант спасения после FAIL Э1 PUMP4×REZHIM_V1 (27.10.2026, ДО расчёта ширины на истории)
Основание: `prereg/PREREG_PUMP4_REZHIM_V1_2026_10_27.md`, результат Э1 `results/pump4_rezhim_e1_20261027T0510Z.json` (коммит 17da8a9).

## Причинный постмортем Э1 (FAIL, класс причины — МЕХАНИЗМ сформулирован слишком широко)
Э1: 608 сделок; BULL 235 −0.046R, не BULL 373 +0.079R; знак одинаков в обоих окнах и каждый год; случайный шорт по режимам
не различается (−0.008 / −0.004) → это свойство PUMP4, а не бета шорта. FAIL по (б): доля бутстрапа ≤ 0 = 5.15 % при пороге 5 %.
Почему: минус BULL почти целиком — один эпизод, 2024-Q4 (59 сделок, −0.31R, −18.2R); без него BULL-сделки +0.04R.
Значит, вредит не «BTC в тренде», а массовая волна пампов альт (альт-мания), которая бывает внутри BULL, но не каждый BULL.
REZHIM_V1 как фильтр PUMP4 дальше не продвигается (Э2 по нему не запускается — правило prereg).

## Вариант (механизм уже записан 26.10 в PREREG_PUMP4_REZHIM_SHIRINA, пороги оттуда, не подбираются)
Ширина = число сигналов PUMP4 V1 по всем монетам вселенной в окне [ts − 24 ч; ts) того же непрерывного повтора.
Шорт против волны проигрывает. Правило F_SHIRINA: брать сигнал, только если ширина ≤ 2; отрезаются сигналы с шириной ≥ 3.
## Раскрытие
- Ширина на истории 2023–2025 НЕ считалась. Но известно, что в 2024-Q4 было много BULL-сигналов (59 за квартал) → ширина там,
  вероятно, высокая. Поэтому добавлено условие (д): эффект обязан держаться при исключении любого квартала, включая 2024-Q4.
- В 84 сделках вперёд ширина 6+ была плохой (7 сделок), ≤2 — лучше; это формирование гипотезы, не проверка.

## Проверка на истории (те же сделки Э1: 2023-03…2025-09, 137 монет, тот же код повтора)
PASS, если одновременно: (а) n(≤2) ≥ 30 и n(≥3) ≥ 30; (б) превышение (R − случайный шорт) «≤2» минус «≥3» > 0, недельный бутстрап
(2 000, seed 27) — доля ≤ 0 не больше 5 %; (в) тот же знак в окнах 2023-03…2024-02 и 2024-03…2025-09; (г) средний R отрезаемых (≥3) ≤ 0;
(д) разница средних R «≤2» − «≥3» > 0 при исключении каждого календарного квартала по очереди.
PASS → один прогон на запечатанном окне 2025-10-01…2026-08-11: n групп ≥ 20, R(≤2) > R(≥3), R(≥3) ≤ 0, бутстрап доля ≤ 0 не больше 10 %.
PASS запечатанного → журнал вперёд (уже идёт по PREREG_PUMP4_REZHIM_SHIRINA) и пакет «PUMP4 V1 + F_SHIRINA» для решения владельца о TINY.
FAIL → семейство «фильтр режима для PUMP4 на истории» закрыто; PUMP4 V1 остаётся как есть; вперёд продолжается только prereg 26.10.

# PREREG ALPACA H5b — BIL с воротами ставки и полосой (19.10.2026, ДО прогона H5b)
Причинный вариант спасения после H5_FAIL (ALPACA_H5_KESH_V_BIL_ITOG_2026_10_19): провал только в P2 (−0.15 / −0.05 п.п.),
причина — перекладка фонда 366 раз при ставке ≈ 0 в 2020–2021 (издержки > купона). Бюджет спасения: это единственный вариант.
Всё как в PREREG_ALPACA_H5 (62cae66) — книга, механика, данные, издержки 3/10 bps, вселенные, правило вердикта — кроме двух
изменений, фиксированных здесь и не перебираемых:
1. Ворота ставки: на сессию t фонд разрешён, если BIL_all.close(t−1) / BIL_all.close(t−64) − 1, приведённое к году
   (×252/63), ≥ 1.0 %. Иначе цель = 0 (продать фонд целиком на открытии t). Используется только BIL (и для руки SGOV —
   те же ворота по BIL: у SGOV нет истории до 2020).
2. Полоса: если цель > позиции, докупка только когда цель − позиция > 5 % капитала на открытии t; если цель < позиции —
   продажа сразу до цели (без полосы).
Вердикт — правило H5 без изменений (≥ +0.5 п.п., DD ≤ +0.5, ≥ 0 в P1/P2/P3, кризисы не хуже −0.5, стресс 10 bps > 0),
на обеих вселенных. PASS → H5B_DEV_PASS → change request Codex по CHANGE CONTROL; исторический PASS GO не даёт.
FAIL → терминально: H5 FROZEN, свободный кэш остаётся кэшем до новых данных (например, процент Alpaca на кэш).

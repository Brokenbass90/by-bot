# PREREG TSMOM_BTC_ETH — недельный тренд BTC/ETH по знаку 12 недель (22.10.2026, до PnL-прогона)

## Основание
Замеры механизма (prereg 4864909, правило решения → K_PNL_TESTU): на окне 08.2017–04.2021 следующая неделя после роста за 12 недель
в среднем на 2.9% лучше, чем после падения (BTC+ETH, t 2.11; по отдельности BTC t 1.41, ETH t 1.58), при 4 неделях 3.2% (t 2.3),
при 26 — 0.9% (t 0.69); VR(4) BTC 1.16, ETH 1.22. Оговорка: BTC и ETH сильно коррелированы, объединённый t завышен.

## Правило (одна версия, классика, без перебора)
- Решение раз в неделю по закрытию воскресенья UTC; исполнение по открытию понедельника (= закрытию воскресенья в данных).
- Направление по каждой монете: знак лог-доходности за прошлые 12 недель: > 0 → лонг, < 0 → шорт.
- Размер: целевая волатильность 20% годовых на монету: вес = 0.20 / (σ недельная за 12 недель × √52), не больше 1.5. Портфель —
  половина капитала на BTC, половина на ETH.
- Расходы: 8 bps на сторону от оборота при каждой смене веса; лонг — спот, без фандинга; шорт — перпетуал, платит 1 bp за 8 ч
  (консервативно; исторически шорты чаще получали фандинг).
- Окно: KRIPTO_D1_2017_2021 (новое, DEV): решения с 12-й полной недели после 17.08.2017 по 30.04.2021.

## Контроль и критерий (заморожены)
- Контроль 1 (тайминг): 2000 перестановок знаков позиций по неделям (сид 20261022) с теми же весами и расходами — доля, где
  результат не хуже стратегии, = p.
- Контроль 2 (описание): «купить и держать» с тем же целевым риском.
- Метрика: средняя недельная доходность портфеля после расходов, t = среднее / (σ/√n).
- PASS = t ≥ порога окна (реестр, k попыток, α 0.20), p перестановок ≤ 0.10, и результат > 0 у BTC и ETH по отдельности. Иначе FAIL.
- Описание, не критерий: те же правила при 4 и 26 неделях; только лонг (шорт → вне рынка); по годам; макс. просадка.
- При PASS: подтверждение на KRIPTO_D1_2021H2_2022 (тем же правилом, одна попытка) и тень вперёд. LIVE — только по GO владельца.
- Деньги: % годовых и $ на депозит $1000, макс. просадка в % и $.

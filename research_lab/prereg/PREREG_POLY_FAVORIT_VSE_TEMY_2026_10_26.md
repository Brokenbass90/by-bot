# PREREG POLY_FAVORIT_VSE_TEMY — ставка на фаворита за сутки до конца в НЕкрипто-темах (26.10.2026, до загрузки данных)
Вопрос владельца 26.10: «много инфоповодов кроме биткоина; ставки на высокий шанс победы». Уже проверено (не повторяется): POLY_FAVORIT_SUTKI
19.10 — только крипто-страйки, NEGATIVE (−2.4 % на ставку; YES переоценён на всей лестнице). Здесь — только НЕ крипто-цены.
Механизм: смещение «фаворит — лонгшот» — розница переплачивает за дешёвые исходы (5–20 ¢), поэтому сторона-фаворит (80–95 ¢) дешевле своей
вероятности. Почему не арбитражировано: деньги заморожены до расчёта, хвостовой риск −100 % на ставку, мелкие рынки.
Данные (загрузчик `poly_favorit_temy_zagruzka.py`, владелец): из каталога `data/poly/katalog` — закрытые бинарные Yes/No рынки с endDate
2024-01-01…2026-10-20, оборот ≥ $100 000, без крипто-цен (регулярка bitcoin|ethereum|solana|xrp|btc|eth|crypto|token|price of);
случайная выборка ≤ 3 000 (seed 20261026); ряд цены YES (CLOB prices-history, fidelity 60) за [end − 48 ч, end], итог — Gamma outcomePrices.
Тема — по тегам/названию события: politics, sports, geopolitics, economy, other (правила в коде загрузчика, до данных).
## Правило (заморожено)
T = endDate − 24 ч; цена p — последняя точка ряда в (T − 6 ч, T]; нужна хотя бы одна точка после T (рынок ещё торговался).
p ∈ [0.80, 0.95] → купить YES по p + c; p ∈ [0.05, 0.20] → купить NO по (1 − p) + c. c = 0.01 (полспреда), стресс c = 0.02.
Комиссия тейкера по теме (docs.polymarket.com/trading/fees, консервативно для всего окна): politics 0.04, geopolitics 0, остальное 0.05,
× p(1−p) на долю. Держать до расчёта. Доход на $1 = (выплата − цена − комиссия) / (цена + комиссия).
Единица — событие (рынки одного события коррелированы): средний доход ставок события; t по событиям; половины — по медиане endDate.
## Вердикт
POSITIVE_LEAD (→ тень вперёд по живым ценам, без денег): ≥ 100 событий, среднее > 0, t ≥ 2.5, обе половины > 0, при c = 0.02 среднее > 0.
NEGATIVE: среднее ≤ 0. Иначе INCONCLUSIVE. Описательно: калибровка по корзинам цены, результат по темам, только фавориты против только лонгшотов.
Оговорка: оборот ≥ $100 000 измерен на конец жизни рынка (знание будущего в отборе) — поэтому это только исследование; вердикт денег — вперёд.

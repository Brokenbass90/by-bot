## Метрики и решение
ГЛАВНАЯ (A): Rank IC STAB21 в широком пуле top-100 по здоровью (больше бумаг на дату → меньше шум).
ВТОРАЯ (B): Rank IC STAB21 в пуле top-18 (как в H2).
k = 2 → t_req = 2.24; t — Ньюи–Уэст, лаг 2, по месячным датам; подтверждение — moving-block bootstrap (блок 4).
Вердикт — по каждой вселенной отдельно:
- первая оценка не раньше 18 месячных дат с завершённым 42-сессионным исходом; до этого — только проверка качества данных;
- PASS: (A) t ≥ 2.24 и среднее IC > 0 и бутстреп-CI выше 0;
- FAIL: на 18-й дате среднее IC(A) ≤ 0; или к 36-й дате нет PASS;
- иначе INCONCLUSIVE до 36-й даты (одна промежуточная оценка на 27-й дате с тем же порогом).
Портфель (отчётно, без права вердикта): теневые книги BASE и H2 (z-сумма, как в H2) по каждой вселенной, 20 bps.
PASS H2b не меняет Monthly: для этого нужен отдельный change request с портфельным подтверждением и GO владельца.

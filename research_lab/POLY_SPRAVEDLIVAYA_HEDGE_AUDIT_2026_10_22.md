## 1. Полный расчёт на $10 (пример: рынок около «денег», σ BTC 40 %, сутки)
p* = 0.30 (модель), YES на Polymarket 0.33 (+3 ¢), покупаем NO.
| величина | значение |
|---|---|
| цена NO с разрывом до VWAP (+0.72 ¢) | 0.677 |
| комиссия Polymarket 0.07·p·(1−p) за токен | 0.0153 → цена 0.6923 |
| токенов на $10 | 14.44 |
| ожидаемая выплата 0.70 × 14.44 | $10.11 → **+$0.11 (+1.1 %) до хеджа** |
| дельта: φ(d2)/(σ√τ) = 0.348 / (0.40·0.0523) | 16.6 → **номинал хеджа 14.44 × 16.6 ≈ $240** |
| Bybit тейкер 0.055 % вход + выход | $0.26 |
| фандинг ~3 начисления × 0.01 % | ≈ $0.07 |
| **итого хедж** | **≈ $0.34 = 3.4 % от $10** (0.14 % от номинала хеджа) |
| ожидание после хеджа | **≈ −$0.23** → по правилу вход не делается |
**«2 % на круг» в моём прошлом сообщении — это процент от $10 позиции Polymarket** (0.11 % от номинала $200), то есть ≈ $0.22, а не $4.
Оценка DeepSeek «$200 × 2 % = $4» — ошибка единиц.

Комиссия Polymarket проверена по документации (docs.polymarket.com/trading/fees): fee = C × 0.07 × p × (1 − p), C — число токенов;
максимум 0.0175 $ за токен при p = 0.5, то есть **3.5 % от суммы сделки** (пример документации: 100 токенов по $0.50 → $1.75).
«1.75 % от суммы» — неверно: 1.75 ¢ на токен = 3.5 % при цене 0.5. В коде — ровно формула документации. Дата введения комиссии на
крипто-рынках — UNKNOWN (на истории комиссия применена ко всем датам, то есть консервативно).

## 2. Замороженное правило на 1 157 исторических рынках (только модельные ожидания, без исходов)
- Проходят фильтр (ожидание со стрессом и хеджем > 0): **655 рынков (57 %)** ≈ **~640 входов в год**, YES 267 / NO 388.
  **Мой прогноз «входы будут редкими» был неверен.**
- Среднее модельное ожидание прошедших — **+22 %** со стрессом (+33 % без хеджа). Номинал хеджа: медиана **$250**, максимум **$2 454** на $10.
- Маржа: при ~6 одновременных позициях номинал хеджа — порядка $1.5 тыс., до ~$10 тыс. в пике; при плече 10× это ~$150–1 000 маржи
  на Bybit сверх ~$60 на Polymarket.

**Вывод:** модель обещает +22 %, а реализуется около нуля. Главная причина — **модель ошибается в хвостах** (нормальное распределение
и 7-дневная σ недооценивают крупные движения крипты), плюс хедж забирает 3–4 % и не идеален: опцион нелинейный, перп линейный.
Это риск-нейтральная, а не истинная вероятность — замечание PM подтверждается данными.

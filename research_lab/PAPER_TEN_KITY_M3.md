# Бумажная тень KITY_M3_POTOK — порядок (заморожен 2026-10-05, до первого сигнала)

Цель: невиданные вперёд данные + операционная проверка живого контура до READY_FOR_CANARY. Не исследование: правило
и вердикт KITY M3 (READY_FOR_BUILD) не меняются. Скрипт `kity_m3_ten.py`: только публичный Binance, нет ключей, нет ордеров.

## Квитанция недели (операционная; доходность одной недели — справочно, это шум)
PAPER_WEEK_OPERATIONAL_PASS ⇔ ≥ 30 монет; сигнал посчитан до закрытия дня d; все 10 позиций проходят мин. лот/номинал при $100;
есть цены входа/выхода у всех ног; сверка с архивом: все признаки совпали (расхождение < 1e-4) и корзина 10/10.
Иначе OPERATIONAL_FAIL с причинами. Решение по canary на 15.10 опирается на операционные проверки 08–09.10 (сигнал, вход,
сверка, лоты) + PASS Codex по исполнению + письменное GO владельца. Доходность недели в решение не входит.

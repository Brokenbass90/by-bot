# Отчёты о сделках в Telegram и веб — контракт research → Codex (16.10.2026)

## Что владелец получает
На каждое событие сделки любой рукав (Alpaca, KITY micro, будущие) шлёт в Telegram карточку-картинку (PNG) + 2 строки текста,
и та же карточка видна в вебе в ленте сделок:
| событие | картинка | текст |
|---|---|---|
| ВХОД (fill) | свечи, ▲/▼ точка входа, линии вход / стоп / цели | «NET · ЛОНГ · вход 311.22 · стоп 277.69 · риск $10.9» |
| ПЕРЕНОС СТОПА (храповик) | те же + новая линия стопа | «стоп 277.69 → 290.10 (риск ↓)» |
| ВЫХОД | + ✕ точка выхода | «▲ +$17.89 (+22.4%) · комиссии · фандинг · причина» |
| ЕЖЕДНЕВНО | сводка открытых позиций (по карточке на позицию) | итог дня по рукавам |
P&L всегда со знаком и стрелкой, не только цветом. Метка «ДЕМО/PAPER» на всём, что не реальные деньги.

## Разделение
- Claude: `research_lab/otchety/karta_sdelki.py` — чистая функция `risovat(sdelka, bars, put) → PNG` (без сети и ключей),
  формат события TradeCard v1 (в шапке файла), образцы demo_closed.png / demo_open.png.
- Codex: подписка на свои события исполнения (fill / stop-amend / exit) → сбор баров из своего источника → вызов `risovat` →
  отправка в существующий Telegram-бот (`sendPhoto`) и запись в веб-ленту. Ничего в ордерах/рисках не меняется; отказ отрисовки
  не блокирует торговлю (отчёт — побочный канал).
- Те же поля события = строки TAX-A (fill/fees/funding/realized) — одна правда для отчёта и для налогового журнала.
Зависимость: matplotlib в окружении бота (`pip install matplotlib`).

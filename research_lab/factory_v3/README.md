## Правила дизайна из калибровки (13.10)
- Порог растёт с числом попыток: край размером с KITY находится в 74% случаев при k=1 и лишь в 16% при k=100. Поэтому бюджет окна DEV — 20 попыток, α 0.20 (скрининг), затем ОДНА попытка в окне CONFIRM с α 0.05.
- Окно `okno_parametry`: бюджет можно только уменьшить, α задать — только до первой попытки.
- Любое изменение кода фермы обязано сохранить паспорт: `kontrol_fermy.py` сравнивает с эталоном и поднимает TREVOGA.

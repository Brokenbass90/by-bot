# КОНЕЧНАЯ ЦЕЛЬ: автономная мультирыночная Trading OS (зафиксировано 12.10.2026, владелец + PM + Claude)

Одним предложением: машина, которая сама смотрит несколько рынков, держит много специализированных проверенных стратегий,
понимает контекст, учится выбирать между ними и распределять капитал, замечает деградацию и лечит себя, через Фабрику
постоянно ищет замену — и сама разговаривает с владельцем.

## Архитектура
DATA (+ автоматический QA данных) → MARKET SCANNERS → PROVEN SLEEVES → CONTEXT / FEATURE STORE →
LEARNED + DETERMINISTIC SCORERS → PORTFOLIO BRAIN → RISK / EXPOSURE → EXECUTION → JOURNAL / EXECUTION LEDGER →
HEALTH / DEGRADATION → FACTORY → CHALLENGERS (стратегии и модели) → обратно в SLEEVES / SCORERS.
Рядом: META-BRAIN (локальный DeepSeek/Qwen через Ollama) и СЛОЙ ОБЩЕНИЯ с владельцем.

## Пять свойств «живой» системы и чем каждое обеспечено
| свойство | механизм |
|---|---|
| сама развивается | Фабрика: генерация гипотез (в т.ч. meta-brain) → prereg → проверка → тень → канарейка; challengers для скореров |
| сама ищет | сканеры рынков + сборщики уникальных данных вперёд (ликвидации V2, стакан, OI, funding/basis, ETB, Polymarket) |
| сама применяет | проверенные sleeves → portfolio brain → риск → исполнение; деньги только через ворота и GO владельца |
| умнеет | ML-scorer как challenger детерминированной политике; обучение на объединённых causal-данных sleeves + тени + история, строгий OOS без утечек; LIVE — проверка реальности |
| лечит себя | QA данных (метки, время, дыры), health-слой: деградация по заранее записанному правилу → капитал вниз / снятие → замена из Фабрики; инженерная самопроверка контуров (guard, восстановление) |
| общается | ежедневная сводка владельцу: что изменилось в деньгах, что дальше, что нужно от него; тревоги — сразу |

## Рынки
Крипта первой; акции через Alpaca; позже Gold/FX отдельными sleeves; arbitrage/basis/funding/cross-venue — отдельный класс.

## Правила
- Meta-brain (LLM) = исследование и советы: аномалии, гипотезы, постмортемы, тексты/события (в т.ч. Polymarket). Прямых прав на
  деньги и риск не получает никогда; его гипотезы идут через тот же prereg.
- Смерть Brain V1.1 убила ЭТУ политику, а не концепцию мозга. Мозг — центральная часть конечной системы.
- Адаптация = обнаружение деградации + замена + переобучение challengers в тени, а не хаотичное online-обучение на деньгах.

## Порядок (money-first)
1. Сейчас: Alpaca → tiny LIVE; KITY → canary (15.10, 22.10); больше независимых проверенных sleeves. Ничто не задерживает 1.
2. Средний срок: автоматический QA данных, execution ledger, feature store, health/degradation, ежедневная сводка владельцу.
3. Дальше: ML-scorer challenger (LightGBM/XGBoost → neural), model registry (MLflow), drift/calibration, meta-brain.

## Модуль TAX & ACCOUNTING OS (добавлено 15.10.2026, владелец + PM)
Стратегический модуль Trading OS: цифровой налоговый помощник — неизменяемый финансовый журнал → сверка → классификация →
налоговые правила по году (Кипр первым) → расчёт → доказательства/происхождение средств → декларация → подача и оплата только
с подтверждения владельца. Полный план: TAX_ACCOUNTING_OS_ROADMAP.md. Сейчас ROADMAP ONLY; ближайшее требование (TAX-A) —
журналы реального исполнения сохраняют учётные данные с первой сделки. Денежные контуры не блокирует.

# PREREG BRAIN_V2 — этап 1: Context Engine (shadow-only) — 17.10.2026

Решение PM: BRAIN_V2 = P1, модульно, сначала тень. Порядок этапов — по наличию данных: (1) контекст → (2) детектор
деградации (с первых живых исходов Alpaca/KITY) → (3) скоринг стратегий (≥3 стратегии × ≥20 исходов) → (4) аллокатор +
оркестратор → (5) ИИ-анализ причин. Этот prereg — только этап 1.

## Что делает
`factory_v3/kontekst_v2.py`, вызывается из `brain_shadow_v1.kontekst()`: к ContextRecord v1 добавляется блок `kontekst_v2`.
Политики BASELINE_V1 / BRAIN_V1 / HEDGE_V1 и их sha **не меняются** — поля только записываются.

# Research → TINY: existing candidate handoff

This is a handoff format over existing executors, not a new allocator or trading engine. Claude owns frozen research and economic verdicts. Codex verifies data/execution and owns the canonical roadmap. Only the owner approves exact financial scope. A research PASS never grants order permission.

For one published candidate supply:

| Required evidence | Acceptance |
|---|---|
| Research revision, immutable spec/universe/parameter hashes | Exact identity, no implicit merge or retuning |
| Prereg economic verdict and limitations | PASS/FAIL/INCONCLUSIVE remains distinct from engineering status |
| Saved signal + observed/available/decision timestamps | Same producer/adapter decisions, no hindsight/retiming |
| Frozen entry/stop/targets/fractions/expiry/hold | Replay, partial fills, lost responses, restart and native protection with existing primitives |
| Dated instrument/quote/depth/fee/funding/margin capture | Decimal quantity/lot/notional, realistic net costs and stress loss; no zero-fee inference |
| Current account and one-writer ownership map | Existing strategies/positions isolated; no second financial owner |
| ORDERS_OFF actual-source receipt | No broker writes; source failures/unknowns block admission |
| Separate exact financial packet | Budget/exposure/reserve/risk/loss latches, expiry/custody and owner GO; no automatic promotion |

Keep per-gate status, exact input hashes, evidence path, blocker and next bounded action. Model PnL, counterfactual Brain advice and real executions must remain separate. Reuse shared lifecycle/account-lock/reconcile primitives; never transplant an old money scope or silently normalize conflicting contracts.

Current priorities come only from ROADMAP_SELF_IMPROVING.md. As of29Oct, KITY new engineering is ON_HOLD for economics; the worked example is retained without money promotion.

# Дорожная карта

**Один файл, перезаписывается целиком.** 21 сентября 2026. Здесь только цель,
этапы и приоритеты. Статусы стратегий — в `research_lab/data/reestr.json`
(единственная машинная база), человеческий вид — `research_lab/STRATEGY_MASTER.md`
(генерируется), доказательства — `research_lab/fabrika/verdikty.jsonl`.

## Цель

Портфель из 4+ независимых ног, каждая с маленькими живыми деньгами, каждая прошла
путь `история → нетронутые данные → тень → PAPER → tiny-live` и сама отключается
при деградации. Четыре **слота**, а не четыре обещанных победителя:

| слот | сейчас в слоте | если нога умрёт |
|---|---|---|
| акции | Alpaca (READY_FOR_BUILD, PAPER 0/7) | фабрика ищет другую |
| крипта: падение | ATT1-short (тень, canary у Codex) | то же |
| крипта: нейтральный/боковик | XSEC (тень + честный PIT-тест) | то же |
| крипта: рост | Bull Continuation (тест идёт), SBR1-major8 (тень) | то же |

Золото/FX/CFD — отдельные слоты позже, после данных.

## Роли

* **Codex:** Alpaca PAPER → 7/7 → dossier → ATT1 production/canary. Research не трогает.
* **Claude:** фабрика, реестр, новые механизмы, счёт теней, пакеты для Codex.
* **Фабрика (daemon):** сама берёт гипотезу, судья выносит вердикт, пишет в реестр.
* **Владелец:** только переход к деньгам и крупные смены направления.

## Этапы

1. **Сейчас.** Codex — Alpaca. Фабрика — Bull. Данные: цены всех ~750 инструментов,
   вселенная топ-50 по OI в долларах.
2. **Пакет v3** (заморожен 21.09): REGIME_V1 (метка), XSEC_EXACT_TARGET_WEIGHTS_PIT
   (+ диагностика на 62 монетах тени), XSEC_3D_REVERSAL, BULL_LEADER_PULLBACK база/фильтр,
   BULL_VOL_EXPANSION база/фильтр.
3. **Каждая находка:** подтверждение на нетронутом окне → проспективная тень → пакет для Codex.
4. **Перед tiny-live:** риск-политика из реальных данных выживших ног — малый бюджет
   риска на ногу, общий лимит экспозиции и корреляции, правила отключения при деградации.
   Конкретные числа (доля риска, число позиций) — только тогда, не раньше.
5. **Масштаб** — только по живым результатам.

## Правила, которые не меняются

* Ни одна нога без контроля случайным входом и без нетронутого окна.
* Никаких переборов параметров; после FAIL не подгонять — новый механизм.
* Лимит «жвачки»: 3 NEGATIVE в семействе на рынке — семейство на паузу.
* REGIME_V1 — метка, не фильтр; пороги не трогаются после результатов.
* Деньги, брокер и tiny-live — только письменное решение владельца.
* Автозапуска на Mac нет (ни launchd, ни cron): фабрика — обычный процесс в терминале.

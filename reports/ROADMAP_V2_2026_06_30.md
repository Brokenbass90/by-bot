# РОАДМАП v2 — единый план вперёд (2026-06-30). Идём, пока не добьёмся.

## Принципы (зафиксированы, не нарушаем)
- **OOS-first:** отбираем по out-of-sample (плато, не пик). In-sample PASS ≠ успех.
- **Асимметричный R:R:** тейк 2–3R, стоп ~1R — прибыль через R, а не через винрейт.
- **Используем МЕХАНИКУ рынка, не угадывание** (carry, pair-arb, уровни, плотности, ликвидации).
- **ИИ = аналитик/настройщик/менеджер в рельсах**, НЕ генератор кода.
- Не хороним и не «замораживаем» — итерируем; деньги идут в то, что доказано.

## Модернизированный ресёрч-цикл (движок поиска денег)
Market survey (где есть условия) → гипотеза → свип Корпатого (тысячи вариантов) →
**отбор по OOS-устойчивости** (≥3/4 окна, плато) → ИИ анализирует результаты
(DeepSeek-как-аналитик: ранжирует, ловит аномалии) → paper → крошечный canary.
ИИ оборачивает КАЖДЫЙ шаг (survey, отбор, флаги), но риск-решения — с аппрувом.

## Треки (параллельно, где позволяет инфра)
**A. ФОРЕКС — новый фокус, первый костяк**
- lookahead-чек всех ~20 стратегий + добавить slippage в движок;
- честный WF range/bounce/mean-reversion (частый флет-отскок) на бесплатных данных;
- свипы с асимметричным R:R; OANDA order/position book = плотности (research);
- позже: demo-исполнение OANDA.

**B. КРИПТА-МЕХАНИКА — деньги без предсказания**
- carry: re-gate на высоком funding + delta-neutral (`carry_neutral`);
- pair-arb (коинтеграция) WF; ликвидации (коллектор уже пишет) → валидация каскада.

**C. КРИПТА-DIRECTIONAL — переписать, OOS-first**
- InPlay V4 (быстрый вход у уровня + асимметричный R:R);
- пампы (вход только после подтверждения разворота);
- ATT1 остаётся live (редкий диверсификатор);
- свипы с отбором по OOS, не по in-sample.

**D. ALPACA — реальный эдж уже сейчас**
- завести $500 live → dry-run → live; позже обернуть ИИ-менеджером (живая на дистанции).

**E. ИИ-АНАЛИТИКА — обёртка над всем**
- `market_survey` (где эджи) → расширить слоями funding/коинтеграция/ликвидации;
- `AdaptiveContextProvider` (тюнинг параметров);
- DeepSeek-как-аналитик (разбор свипов, ранжирование, аномалии) — когда будет бюджет;
- ИИ-портфельный менеджер в рельсах (предлагает, человек одобряет).

`reports/CLAUDE_AUDIT_2026_06_22.md` в ОДНУ доказанную ногу → собранную книгу →
крошечный canary. Делать строго по порядку; между этапами — гейты (стоп, если не
прошли). Все прогоны — на ПОЛНОЙ серверной истории + РЕАЛЬНЫЕ комиссии.

Принцип: деньги только за доказанным эджем. Отрицательный результат = тоже
результат (экономит риск). Человек в контуре на всех решениях о деньгах/коде.

## 2. Граница test — по t_available (часы решений A3)
- Возможность принадлежит сгибу k ⇔ start_k ≤ t_available < end_k (полуоткрыто). ts для границ не используется.
- Новые решения прекращаются на 2025-10-01 00:00; дальше прогон идёт только шагом «освобождение» A3, пока все позиции не закроются.
- **net USD сгиба k** = сумма net USD (A3 §5) сделок, чей t_available в сгибе k, независимо от того, когда они закрылись.
  Критерий «≥ 3/4 сгибов» V1 §6 считается по этим суммам. FUNDING_UNKNOWN — по A4 (исключены, считаются отдельно).

## 3. Просадка развивающего фильтра: DD_ENV (огибающая стопов) вместо MTM
MTM без цен внутри удержания не восстановить, а DD только по закрытым сделкам занижает риск. Поэтому для ИСТОРИЧЕСКОГО фильтра
метрика V1 §6 «сквозная MTM-просадка» заменяется консервативной огибающей, одинаковой для всех рук:
- Для открытой позиции i её худшая возможная оценка: **L_i = min(−1, R_i) · risk_usd_i**
  (стоп не расширяется → внутри удержания хуже −1R не бывает, кроме гэпа сквозь стоп; тогда худшее = итоговый R_i < −1).
  Частичные выходы в потоках не видны (только итоговый R) → позиция целиком считается открытой до release_time;
  её полный net USD зачисляется в E в момент release (A3). Издержки и фандинг в L_i не входят — они признаются при release.
- На каждом тике τ (сетка 15 мин, после шага 1 «освобождение», до пакета):
  **E_env(τ) = E_realized(τ) + Σ_открытых L_i**; пик P(τ) = max(E0, max_{s≤τ} E_env(s));
  **DD_ENV = max_τ (P(τ) − E_env(τ)) / P(τ)**.
- FUNDING_UNKNOWN-сделки в L не входят (A4 §3), их риск занимает лимиты по A4.
- Критерий фильтра: DD_ENV(BRAIN_DET) ≤ 1.1 × DD_ENV(FOUNDATION). Дополнительно в отчёт (не критерий): DD по реализованному E.

## 4. MTM-DD для проспектива (там цены есть) — фиксирую сейчас
- Отметка на каждом тике τ по close последнего закрытого M15 символа к τ (не цена внутри бара, не будущий бар).
- Нереализованный PnL открытой части: side · (close/entry − 1) · notional_open. Частичный выход: его PnL (с комиссией и
  проскальзыванием A3) зачисляется в реализованный E в момент исполнения, notional_open уменьшается. Фандинг — в момент начисления.
- E_mtm(τ) = E_realized(τ) + Σ нереализованных; DD_MTM — как в §3 с E_mtm вместо E_env. Нет close символа к τ → отметка = предыдущая,
  > 1 ч без close → тик помечается STALE и в отчёт идёт их число (порог BLOCKED_DATA — как A3 §4, > 5% тиков у любой руки).

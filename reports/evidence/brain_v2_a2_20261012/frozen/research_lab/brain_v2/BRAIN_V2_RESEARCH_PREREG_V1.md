# BRAIN_V2 — исследовательская спецификация V1 (числа заморожены 11.10.2026, Claude). Реализация — Codex.

Опора: каркас Codex `docs/superpowers/specs/2026-10-08-brain-v2-direction-design.md` (контекст → скорер ноги → аллокатор →
капитал/экспозиция → журнал; руки RAW_SAFE / FOUNDATION / BRAIN_DET / BRAIN_LEARNED). Урок B3 (os2/B3_POSTMORTEM_…):
результат ноги по полугодиям не устойчив → мозг НЕ включает/выключает ноги по недавнему PnL.

## 1. Принципы (из B3, не обсуждаются)
P1. Мозг распределяет капитал между УЖЕ одобренными ногами. Есть ли у ноги edge — вердикт исследования (Factory), не мозга.
P2. Мозг меняет только порядок и размер (0.5×–1.5× базового риска), не допускает/не исключает ногу. Худший случай мозга ≈ FOUNDATION.
P3. Оценки — по длинной истории со сжатием (shrinkage), не по последнему окну. Параметры заморожены; переобучение — только как претендент.
P4. Неизвестное ≠ ноль: неизвестный контекст → откат к оценке ноги без контекста; неизвестные капитал/позиции/защита → стоп новых входов.
P5. Концентрация ограничена структурно (иначе «победа» = одна нога, как SF3 в B3).

## 2. Возможность (общий контракт для всех ног)
`{sleeve, symbol, side, t_signal, t_available, entry_rule, stop_distance_frac, max_hold_h, cost_model_id, source_hash}`.
Размер позиции = риск / stop_distance. Издержки: 6 bps/сторона + 2 bps проскальзывание + фандинг по факту удержания.

## 3. Контекст (V1 — только 2 признака, у каждого есть механизм)
| признак | определение (только закрытые данные, известные к t_available) | механизм |
|---|---|---|
| REZHIM | REZHIM_V1 (bot/regime_orchestrator.compute_regime, замок A1): BULL / BEAR / NEUTRAL / UNKNOWN | направленные ноги зависят от тренда рынка |
| VOL | перцентиль ATR(14, 1h)/цена символа за последние 90 дней: LOW (<33) / MID / HIGH (>67) / UNKNOWN | стоп-ноги зависят от шума/дистанции стопа |
Фандинг, ширина, поток — НЕ в V1: только претендентами V2 с отдельным prereg (по одному, инкрементальная польза).

## 4. Детерминированный скорер (BRAIN_DET)
Ячейка c = REZHIM × VOL (9 ячеек + UNKNOWN). Иерархическое сжатие, оценки по развивающим данным до даты заморозки:
- μ̂_s = n_s·m_s / (n_s + κ0), κ0 = 300 (нога → к нулю);
- μ̂_{s,c} = (n_{s,c}·m_{s,c} + κ1·μ̂_s) / (n_{s,c} + κ1), κ1 = 150 (ячейка → к ноге); UNKNOWN → μ̂_s.
- σ̂_s — стандартное отклонение R ноги; z = μ̂_{s,c} / σ̂_s.
- Множитель риска: mult = clip(1 + 4·z, 0.5, 1.5). Ранг при нехватке мест — по z (ничья → раньше t_available → id).
κ0, κ1, 4, границы — заданы априори здесь, не подбираются.

## 5. Аллокатор и капитал (общие для FOUNDATION и BRAIN_DET)
Капитал E (свой у каждой руки), базовый риск 0.5%·E на позицию; открытый риск ≤ 6%·E; ≤ 12 позиций; ≤ 1 позиции на символ;
доля одной ноги ≤ 40% открытого риска; чистый направленный риск |Σлонг − Σшорт| ≤ 60% открытого риска (вся крипта = один кластер беты).
Пакетирование: возможности с одинаковым часом t_available решаются вместе. Освобождение риска — по фактическому выходу.
RAW_SAFE: тот же капитал и абсолютные лимиты (6%·E, 12 позиций, символ), без лимитов доли ноги/направления, порядок — t_available, mult = 1.
FOUNDATION: RAW_SAFE + лимиты доли ноги и направления, mult = 1, порядок — t_available.
BRAIN_DET: FOUNDATION + ранжирование и mult из §4.
BRAIN_LEARNED: не в V1 (отдельный prereg после того, как BRAIN_DET даст вердикт).

## 6. Доказательства и вердикт
**Развивающий фильтр (необходим, не достаточен):** история 2023-01…2025-09 (потрачена → только «не хуже»), те же 4 сгиба B3,
оценки §4 — только на train каждого сгиба. Пропуск в проспектив ⇔ BRAIN_DET ≥ FOUNDATION по сумме net USD хотя бы в 3/4 сгибов
и сквозная MTM-просадка BRAIN_DET ≤ 1.1 × FOUNDATION. Иначе — STOP V1, разбор, без перебора κ.
**Решающая проверка — проспективная тень** (оценки заморожены на всей развивающей области, хэш до старта):
единица — неделя; первичная метрика — парная разница недельного net USD (BRAIN_DET − FOUNDATION) при равном стартовом капитале.
Смотрим ДВАЖДЫ: на 16-й и 26-й неделе (минимум 300 закрытых сделок в BRAIN_DET к 16-й, иначе ждём до 26-й).
PASS ⇔ средняя разница > 0, t НВ(лаг 1) ≥ 2.3 (поправка на два взгляда) и MTM-DD BRAIN_DET ≤ 1.1 × FOUNDATION.
FAIL ⇔ средняя разница < 0 при t ≤ −1.0 на 26-й. Иначе INCONCLUSIVE (без продления). Та же схема FOUNDATION − RAW_SAFE:
структурный слой обязан окупаться отдельно.
**Отчёт обязательно:** net USD, MTM-просадка от начального капитала, профит-фактор, оборот, издержки отдельно, простой капитала,
занятые слот-часы, концентрация по ногам/символам/направлению, вклад каждой ноги, бутстреп-интервал разницы, реестр всех попыток.

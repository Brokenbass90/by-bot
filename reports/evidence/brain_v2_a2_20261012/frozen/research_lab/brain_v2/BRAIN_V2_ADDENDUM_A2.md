# BRAIN_V2 — дополнение A2 (12.10.2026, Claude). Ответ на 2 вопроса Codex по A1. Числа V1/A1 не меняются.

## 1. «Риск одной ноги ≤ 0.40·B»
Это **сумма риска всех открытых позиций ноги** (например, все позиции BOUNCE1 вместе), а не одной позиции.
Проверка при каждом добавлении: Σ r_j по открытым позициям ноги + r_новой ≤ 0.40·B. Причина отказа — sleeve_cap.
(Одна позиция ограничена отдельно: r_i = 0.005·E·mult ≤ 0.0075·E при mult ≤ 1.5.)

## 2. Соответствие ts потоков B3 и t_available
В потоках B3 (orchestrator.build_trades / os2/signaly.py) `ts` = время ОТКРЫТИЯ сигнального бара базы ноги; сигнал известен на его
закрытии, вход — открытием следующего бара. Замороженное соответствие:
**t_available = ts + длина бара базы ноги**: ATT1, SBR1, ASR1, BOUNCE1 — +60 мин (база H1); ETS2, SF3 — +15 мин (база 15m).
Ячейка, пакет и метка REZHIM — по floor(t_available) к часу; VOL — по последнему закрытому H1 с открытием floor(t_available) − 1 ч.

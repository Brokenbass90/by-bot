# High-impact идеи + вердикт по intraday Alpaca (Claude, 2026-06-15)

Для переезда в новый чат и для сессии Codex. Приоритет по импакту/риску.

## Вердикт: внутридневная Alpaca
Не убивать, но низкий приоритет. Путь к «скромному бойцу»: (1) явно короткий свинг 1-3 дня (обход PDT), (2) ATR-стопы вместо ~0.45% (сейчас выбивает на шуме), (3) PF>1 на OOS включая медведя. На счёте <$25k — вторичный equity-рукав, не работяга.

## Идеи, которых нет (или не построены) — по импакту
1. **Maker / post-only входы (НЕ реализовано; входы Market/IOC).** Высший импакт по доходности: ASB1/ARF1 входят от уровня → post-only возвращает ~5-10bps/сделку = разница между ASB1 +0.18R и +0.41R после комиссий. Это апгрейд ИСПОЛНЕНИЯ, не новая стратегия. Фолбэк в taker при уходе цены. **Делать первым.**
2. **Funding-carry как живой market-neutral рукав** (каркас есть, 0 закрытых циклов). Структурный некоррелированный доход → сглаживает просадку портфеля (3-й рукав из проектора). Валидировать ≥10 прибыльных shadow-циклов → малый live.
3. **Входы по каскадам ликвидаций** (Bybit WS liquidation feed). После стоп-каскада — mean-reversion отскок; усиливает вход ASB1/ARF1. Крипто-структурный эдж.
4. **Cross-sectional ранжирование** вместо фиксированных порогов: ранжировать всю вселенную по силе сигнала, брать топ-K. Прямо лечит «фиксированный гейт режет 90% входов» (наша причина 0 кандидатов) — порог адаптивный, частота управляемая.
5. **Meta-labeling** (вторая модель take/skip поверх сигнала). Фильтрует низковинрейтный поток в качественный. AI-скорер — примитив; обученная мета-модель — апгрейд качества без новых стратегий.

## Честно про импакт
- №1 (maker) и №2 (funding-carry) — наиболее надёжны (механика комиссий + структурный эдж), низкий риск. Делать в приоритете.
- №3-5 — повышают качество/частоту, но требуют валидации через тот же гейт (WF ≥3/4 + PF>1 + двойной тест).
- Идеи сами по себе эдж не создают; ценность — в исполнении и структуре, проверенных на OOS.

# ATT1 short r001 — решение по миграции canary + разгон (2026-07-02, Claude)

## Веха
ATT1 short r001 — ПЕРВЫЙ кандидат, прошедший ПОЛНЫЙ строгий барьер:
- strict folds 4/4 net>0, robust plateau, peak ratio 2.35 (НЕ one-window hero);
- 239-307 сделок (большой N); 2 красных месяца;
- FEE/SLIP-STRESS ВЫЖИВАЕТ: 6/2bps +27.77R PF1.40; 10/5bps +16.53R PF1.21.
Это первый честно-валидированный крипто-эдж. Потенциал: ~14%/год @0.5%, ~21%/год @0.75%, DD~3-5%.

## Решение (рекомендация Claude)
r001 > текущего live-конфига (у live 4-5 красных мес, ниже PF). Миграция ОБОСНОВАНА OOS.
Порядок БЕЗОПАСНЫЙ (Claude готовит config, Codex деплоит, владелец OK):
1. МИГРИРОВАТЬ ATT1 canary на r001-геометрию, риск ОСТАВИТЬ tiny (0.10). НЕ поднимать при миграции.
   (Меняем только геометрию на доказанную; риск не трогаем — сначала подтверждаем live.)
2. Собрать 10-20 live short-сделок -> edge_monitor healthy (реализованный R ~ baseline).
3. ТОЛЬКО тогда разгон через smart_risk по плану: 0.10 -> 0.25 -> 0.5 -> 0.75, каждый шаг
   подтверждается live healthy, анти-мартингейл, breaker+expiry, hard_cap<=1%.
4. Откат на шаг вниз при любом edge-decay/halt.

## Честная оговорка
r001 — ЛУЧШИЙ из прошедших (мягкая selection). Барьер строгий (4/4 фолда + fee-stress),
так что риск оверфита низкий, НО финальное доказательство — ЖИВЫЕ сделки. Поэтому риск tiny
до подтверждения. Не поднимаем вручную, только через smart_risk по живым данным.

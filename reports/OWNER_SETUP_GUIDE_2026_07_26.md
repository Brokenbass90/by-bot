# Что нужно от владельца для следующих контуров

Дата: 2026-07-26. Это руководство не разрешает live-торговлю и не требует
передавать секреты в чат.

## Сейчас — без оплаты и без новых денег

1. **ATT1:** ничего регистрировать не нужно. Оставить tiny-canary `x0.10`,
   пока владелец сам не поставит стратегию на паузу.
2. **XSEC V4:** аккаунт и ключи пока не нужны. Risk-zero shadow уже собирает
   решения; сначала нужны fill-rate, turnover и paper slippage.
3. **Cross-exchange funding:** ключи и деньги пока не нужны. Public-data
   lifecycle должен набрать не менее 20 чистых закрытых циклов после исправления
   политики закрытия.
4. **Alpaca Safe Hold:** ничего не покупать и не доливать. ABBV/SCHW защищены
   брокерскими stop-ордерами; новые входы запрещены.

## Alpaca: что сделать первым

1. Зарегистрировать бесплатный **Massive Stocks Basic**.
2. Создать market-data API key.
3. Не отправлять ключ в Telegram, Codex или Git. Сохранить его локально в
   отдельном env-файле через будущий setup-скрипт.
4. Сначала проверить бесплатные 2 года истории на PIT-universe, delisted,
   splits/dividends и точное соответствие сигналов. Платный тариф пока не нужен.
5. Если бесплатный слой не закрывает проверку, взять **Stocks Starter $29**
   только на один месяц. Developer `$79` не покупать без отдельного отчёта о
   том, какой конкретно недостающий endpoint он разблокирует.

Это покупка данных, а не акций. Текущий капитал около `$484` достаточен для
fractional-исполнения, но недостаток капитала сейчас не является главным
блокером — главный блокер точная PIT/parity-проверка модели входов.

## FX/CFD: минимальный следующий шаг

Если OANDA v20 доступна для страны регистрации:

1. Открыть бесплатный **fxTrade Practice** account — без депозита.
2. В кабинете: `My Services -> Manage API Access`.
3. Создать personal access token и сохранить отдельно.
4. Нужны два значения: practice account ID и token. Не присылать их в чат;
   будет подготовлен локальный setup-скрипт.

Practice API нужен не для немедленной торговли, а чтобы получить реальные
instrument specifications, bid/ask, spread/session behaviour и затем вести
demo-shadow. Если OANDA v20 недоступна, альтернативой служит MT5 demo и экспорт
Specifications для:

- EURUSD
- GBPUSD
- USDJPY
- EURJPY
- GBPJPY
- XAUUSD

Для каждого инструмента нужны spread, commission, swap long/short, contract
size и minimum lot.

## Cross-exchange funding: только после paper gate

Предпочтительный первый маршрут — **Bybit + Bitget**, потому что адаптеры и
public-data наблюдения уже ближе к готовности. MEXC можно добавить вторым
этапом; BingX — после отдельной проверки API и исполнения.

После успешного paper lifecycle:

1. Два верифицированных аккаунта.
2. Отдельные subaccounts для бота.
3. Trade-only API keys, **withdrawal запрещён**.
4. IP allowlist на IP live-сервера.
5. Начальный тестовый капитал ориентировочно `$100–200` на каждую биржу.
6. Сначала risk-zero connectivity, затем минимальный paper/live canary.

Не переводить деньги и не создавать trade keys до отдельного `GO`-receipt.

## Безопасность

- Не хранить секреты в Git.
- Не показывать ключи на скриншотах.
- Разделять research, paper и live credentials.
- Включать withdrawal только вручную вне API; у bot keys он должен быть
  выключен всегда.
- При случайной публикации credentials — немедленно revoke/rotate.

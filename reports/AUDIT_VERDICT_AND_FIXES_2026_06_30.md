# Аудит claims DeepSeek по реальному коду + что починено (2026-06-30)

Claude проверил утверждения DeepSeek ПО ФАКТИЧЕСКОМУ коду (DeepSeek анализировал
присланный фрагмент и местами угадывал). Вердикт:

## Подтверждено (верно) и ПОЧИНЕНО
- **ARF2 объёмный фильтр выключен по умолчанию** (`min_reject_vol_mult=0.0`).
  → FIX: default 1.2 (объёмное подтверждение ВКЛ — это ручной эдж владельца).
- **market_context.atr включал сигнальный бар** → FIX: добавлен `exclude_last=True`
  (бар больше не раздувает свой же ATR-стоп).
- **`max_age_bars` считался, но не фильтровал уровни** → FIX: build_context теперь
  отбрасывает уровни старше `max_age_bars` (свежесть).
- **Наклонные без проверки валидности** → FIX: `sloped_level` теперь возвращает
  `valid` (не пробита ли линия закрытием) + `min_slope_atr` (отсев почти-горизонталей)
  + `require_unbroken`. → наклонные стали «чёткими».
- **Нет «пробитых» уровней для ретест-входов** → FIX: добавлена
  `nearest_broken_level()` (бывшее сопротивление, пробитое вверх, → поддержка).
  → детектор стал универсальным для пробоев И отскоков.

## Подтверждено (верно), но чинит Codex на сервере
- **ARF2 ATR (стр.433) по `rows`, пивоты по `rows[:-1]`** — несогласованность;
  заменить на `rows[:-1]`/`exclude_last`. (Не «машина времени»: rows[-1] закрыт,
  но бар раздувает свой стоп — DeepSeek по сути прав.)
- **ARF2 перефит, 50+ параметров** — упростить по рецепту DeepSeek (убрать
  HVN/VWAP/recency-веса, оставить кластер+касания+буфер+прокол), честный WF.
- **InPlay V3: вход по закрытию 15m → поздний вход → широкий стоп** (PF 0.868) —
  переписать вход (быстрее ТФ / лимитка у уровня), свежесть уровней. Это V4.

## Слегка перегнул (формулировка)
- «ATR lookahead = машина времени» — на деле это самоинфляция стопа сигнальным
  закрытым баром, а не подглядывание будущего. Чинить стоит, но катастрофы нет.

## Где НЕ только горизонтали (ответ на вопрос владельца)
Детектор видит И горизонтальные кластеры, И наклонные (`sloped_level`,
`classify_channel`). ARF2 фейдит горизонтальное сопротивление, НО ASB2/ACB1 уже
используют наклонные (линии канала). Можно добавить и ARF2 фейд наклонного
сопротивления — теперь с `valid`-фильтром это безопасно.

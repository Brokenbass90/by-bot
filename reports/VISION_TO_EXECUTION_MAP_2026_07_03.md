Видение (зафиксировано со слов владельца): все стратегии — пробои, отскоки, отскоки во
флете, Элдер, сдутия пампов, заколы, инплэи — написаны идеально; ИИ постоянно держит руку
на пульсе и подстраивает их под реалии рынка; long/short разделены и управляются

Это НЕ новая идея — это ровно MASTER_MAP Ф1-Ф4. Ниже карта: каждый элемент видения ->

## Что значит «написано идеально» (наш стандарт качества)
1. Каждый модуль: юнит-тесты, причинность (без lookahead), контракт OHLC единый.
2. Каждая нога: за флагом, decision_bus-атрибуция, breaker, canary tiny -> разгон лестницей.
3. Каждый эдж: OOS-фолды + cross-symbol + fee-stress + side-split + per-period. Без исключений.
4. Данные: coverage gate + cost gate ПЕРЕД любым вердиктом (уроки 2026-07-03).
5. ИИ-подстройка: только в рельсах (режим/риск/жизненный цикл), предложения — через
   research_orchestrator на аппрув человека. Свободная подгонка параметров запрещена.

«Идеально написанная» стратегия без доказанного эджа = идеально написанный слив.
Поэтому порядок всегда: код качественно -> данные честно -> эдж доказан -> деньги.

## 2. Если PASS -> безопасный разгон риска через smart_risk (НЕ фикс %)
Пошагово, каждый шаг подтверждается ЖИВЫМИ shadow/canary сделками (edge_monitor healthy):
- Шаг 0 (сейчас): canary risk_mult=0.10, breaker+expiry. Копим live-сделки.
- Шаг 1: rolling-OOS PASS + >=20 live-сделок healthy -> base 0.25% через smart_risk.
- Шаг 2: >=40 live healthy, expectancy в норме vs baseline -> base 0.5%.
- Шаг 3: >=60 live healthy, DD в пределах -> base 0.75% (целевые ~+25%/год при DD~3.4%).
- ВЕЗДЕ: smart_risk режет в high_vol/degraded/просадке (анти-мартингейл), hard_cap<=1%.
- Любой halt/edge-decay -> откат на шаг вниз или в shadow. Никаких ручных бустов.

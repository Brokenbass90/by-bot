# ПРЕ-РЕГИСТРАЦИЯ: расширение юниверса ATT1 short r001 (2026-07-04, Claude)

Цель: ЧАСТОТА без новой стратегии. Та же доказанная r001-геометрия (strict folds 4/4,
fee-stress OK) на расширенном наборе монет. Сетап редкий НА МОНЕТУ -> частота складывается
по монетам. Бонус: это одновременно OOS-SYMBOL тест самого ATT1 (обобщается ли эдж).

## Фиксируем ДО прогона (менять нельзя)
- Параметры: ровно r001 из configs/att1_short_r001_canary_20260702.env
  (pivot 2/3, min_pivots 2, max_age 16, min_r2 0.55, touch_atr 0.50). БЕЗ подкруток.
- Short-only. 60m, 360d, fee 6/2bps + stress 10/5bps.
- БАЗОВЫЙ набор (уже в live): BTC,ETH,SOL,ADA,LINK,LTC,DOT,SUI — в прогон НЕ входит
  (он in-sample по построению). Расширение тестируется ОТДЕЛЬНО.
- РАСШИРЕНИЕ (ликвидные, 5m кэш есть): DOGE,XRP,AVAX,ATOM,BNB,BCH,XLM,1000PEPE,HYPE,TAO,ONDO.
  Перед прогоном: candle_coverage gate (5m, 24/7), символы с дырами — вон из набора ДО теста.

## Пороги PASS (расширение как ГРУППА, не черри-пик)
1. Группа целиком: net_R > 0, PF >= 1.15, 4 хроно-фолда >= 3/4 положительных.
2. >= 60% активных символов с net_R > 0 (активный = >=5 сделок за 360d).
3. Fee-stress 10/5bps: группа остаётся net_R > 0.
4. Частота: суммарно >= 40 сделок/360d по группе (иначе расширение не решает задачу).

## Правила решения
- PASS -> добавить В ALLOWLIST live-канарейки ВСЕ монеты расширения, кроме индивидуально
  дырявых по coverage (не по результату! отбор по результату = черри-пик).
  Риск НЕ меняется (0.10), breaker/expiry прежние. Частота вырастет сама.
- PASS группой, но 1-2 монеты сильно минусовые: ВСЁ РАВНО берём всех (группа = юнит решения).
  Отсев отдельных монет позже — только через edge_monitor per-symbol на live-данных.
- FAIL -> ВАЖНО: это тень на сам ATT1 (эдж может быть узким на 8 монетах). Тогда:
  не расширяем, live не трогаем, но помечаем ATT1 как «узкий эдж» в ledger и
  ускоряем поиск рукава 2 (каскады/FX). Разгон риска ATT1 при FAIL — только до 0.5, не 0.75.
- Частичного PASS нет. Пороги выше зафиксированы 2026-07-04, двигать нельзя.
